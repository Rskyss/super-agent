# 补格式

复查员的回复没有合格的复查清单时，请它只补格式、不重新复查。前面程序还会放上规则包里复查那一份规则。

空位：{原回复}＝复查员上一次的回复全文；{不合格原因}＝一行一条；{上轮核对}＝见《补格式上轮》，没有就为空；{卡片}＝任务卡路径。字段名、“结论”“上轮核对”这些字程序要认，别改。
