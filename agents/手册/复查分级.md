# 复查分级：级别、碰上、类型怎么标，哪些会退回

程序按复查清单里的“级别”“碰上”“类型”和证据方式，自动决定退不退回给写代码的去改。标重了，小问题被一轮轮退回，写代码的为修它改坏别处；标轻了，真问题被放过。

## 只报碰得上的

只报在这个项目里碰得上的问题：要么实跑复现，要么推演时指出本项目里哪段代码、哪个测试会走到它。跑不了也要照实写，不许因为跑不了就不报。

## 级别：【严重】【中等】【轻微】

- 发现改坏了原来能用的功能，一律标【严重】。
- 施工单写了“原有行为清单”的，清单里的行为被改掉，也标【严重】。

## 碰上：常见 / 少见 / 极巧合（每条都要填）

- **常见**＝正常使用容易遇到。
- **少见**＝本项目里会发生、要特定操作才遇到，比如停下后接着跑。
- **极巧合**＝下面任一种：
  - 恰好在两步之间被打断才出的；
  - 页面或数据还在加载、切换项目的那一两秒空档里又连续操作才出的（复查时故意拖慢加载、人为卡时机才复现的也算）；
  - 本项目里根本没有会触发它的写法、文件或操作。

来历：CARD-019（切换项目）复查员把“页面加载那一两秒里又点了别的”标成“少见·严重”，程序照退，三轮退回，写代码的为修它改坏了原来的设置页（11-20 用户定写进来）。

## 类型

- **功能问题**。
- **测试写错**：测试本身写错，和任务卡、施工单对不上。
- **安全或丢数据**：泄露密钥、删掉或写坏用户文件这类。输入框里没发出去的字、界面停在哪一页不算丢数据，按功能问题报。

## 程序怎么判退不退回

1. 测试写错、安全或丢数据：一律退回，哪怕少见。
2. 标“极巧合”的：不退回、只记以后再修，不管是实跑复现还是推演。（11-20 用户定；原来实跑复现的不看这一栏，故意拖慢加载复现的问题照样被退回）
3. 只能推演的“少见”：只有严重的才退回。
4. 其余：严重的退回；第一轮复查时，这次改出来的中等、轻微也退回，原来就有的只退严重的；后面几轮只退严重的。
