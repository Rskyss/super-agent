## 三、具体做法

动手前先看第四节状态表和第五节原有行为清单。

**病根（已实测）**：`main.swift` 里限制拖动范围、记宽度的代码早就有，但 `split.arrangesAllSubviews = false` 之后用 `addSubview` 加三栏，分隔视图认为自己一栏都没有，所以从来拖不动。必须用 `addArrangedSubview`。另外“只有拖分隔线时通知才带 NSSplitViewDividerIndex”这句旧注释是错的：窗口变大变小、程序自己摆放时也带，照它记宽度会把挤窄后的宽度当成用户要的。

### P1 新建 Columns.swift，三栏的摆放和拖动只放这一处

只 `import AppKit`（验收测试会把它单独编译，不能用 main.swift 里的任何东西）。放这些：

- 从 main.swift 挪过来并改数：`navWidthRange` 改成 `200...420`、`rightWidthRange` 改成 `300...640`、`centerMinWidth` 仍是 440。`threeColumnWidth`、各个 `...Key` 留在 main.swift。
- `final class ThreeColumnSplit: NSSplitView`：从 main.swift 挪过来（分隔线颜色、粗细 1 不变），覆写 `mouseDown(with:)`，在 `super.mouseDown` 前后标记“正在拖”（`super.mouseDown` 到松手才返回）。
- `final class ThreeColumns: NSObject, NSSplitViewDelegate`，对外这几样，名字一字不差：
  - `init(nav: NSView, center: NSView, right: NSView, navWidth: CGFloat, rightWidth: CGFloat)`：宽度超出范围就收到范围内；`split` 设成竖向、`.thin`、`delegate` 是自己、`arrangesAllSubviews = false`，三栏依次 `addArrangedSubview`。
  - `let split: ThreeColumnSplit`、`let nav`、`let center`、`let right`
  - `private(set) var navWidth`、`private(set) var rightWidth`：用户要的宽度（窗口挤窄时不变）
  - `var onUserDrag: (() -> Void)?`：用户拖完松手、宽度真的变了，叫一次
  - `func layout()`：按记住的宽度摆三栏。**栏开没开只看 `nav.isHidden`、`right.isHidden`**，不另存一份状态
- 摆放规矩（从 main.swift 的 `layoutColumns` 挪过来，加上左栏收起）：没收起的栏才占宽度和分隔线；只有中间伸缩；放不下时先让右栏再让左栏，都不低于下限；左栏实际宽度不超过记住的宽度。
- 拖动规矩：
  - 左线：左栏不小于 200、不大于 420，也不能把中间挤到 440 以下；右线同理（300～640）。
  - 抓取范围比 1 点的线宽：左右各多 4 点（`effectiveRect`）；收起的那一边没有线、抓不到（`shouldHideDividerAt` 和 `effectiveRect` 返回 `.zero`）。
  - 拖哪条线只记哪一栏：拖左线不能改掉记住的右宽。按下时就定好是哪条线（左栏收起时只可能是右线，右栏没开时只可能是左线，都开着时看按下的位置离哪边近）。
  - 宽度和按下时比变化不到 0.5 点（只点没拖、拖不动）不算拖过，不记、不叫 `onUserDrag`。
  - 拖的过程里边拖边更新记住的宽度（拖到一半程序要是重新摆放，不会跳回去）；松手后 `layout()` 一次，再叫 `onUserDrag`。
  - 窗口改大小、程序自己摆放，一律不改记住的宽度。

### P2 main.swift 接上

- 去掉挪走的东西：`ThreeColumnSplit`、三个范围常量、`splitView(...)` 几个代理方法、`splitViewDidResizeSubviews`、`layoutColumns` 里的算法、`split.delegate = self` 等。`AppDelegate` 不再当分隔视图的代理。
- 新增 `var columns: ThreeColumns!`；`navWidth`、`rightWidth` 两个成员改成从 `columns` 取，不再各存一份；`split` 可以保留为 `columns.split`。`buildWindow` 里读出存的宽度（`navWidthKey`、`rightWidthKey`）交给 `ThreeColumns(`，**在 `window.delegate = self` 之前**建好。`onUserDrag` 里把两个宽度写进 UserDefaults，自测（`selfTest`）时不写。
- `layoutColumns()` 留着，只调 `columns.layout()`。
- 左栏开关：
  - `let navOpenKey = "navOpen"`；`var navWanted = true`；`buildWindow` 里照 `rightOpenKey` 那行写法读 `defaults.object(forKey: navOpenKey) as? Bool`，没存过是展开。
  - `func setNavWanted(_ wanted: Bool)`：照 `setRightWanted` 的样子——`navWanted = wanted`；`if !selfTest { UserDefaults.standard.set(wanted, forKey: navOpenKey) }`；收起时叫左栏页面关掉项目浮层（`window.SuperAgentNav.closeProjectMenu()`，写法照 `closeMenuMonitor` 那处）；然后 `syncNavColumn()`。
  - `func syncNavColumn()`：`navBox.isHidden = !navWanted`，两个按钮的显示、返回聊天的位置跟着变，再 `layoutColumns()`。建窗口时也要叫一次。
  - `@objc func toggleNav(_ sender: Any?) { setNavWanted(!navWanted) }`。
- 两个按钮，样式照 `rightToggle`（同样大小、无边框、圆角），图标 `"sidebar.left"`，颜色用 `dimColor`：
  - `navToggle`：放在左栏顶部细栏（`navTop`）右边，离右边 8、上下居中；提示“收起左栏”。左栏跟着收起，它自然看不见。
  - `navShow`：放在中间顶部细栏，离左边 78（让开红黄绿三个圆点），和 `rightToggle` 同一高度；提示“展开左栏”；左栏展开时隐藏。
  - `action` 都是 `#selector(toggleNav(_:))`。
- 中间顶部的“返回聊天”（`backToChat`）：左栏收起时往右让，离左边 114；展开时仍是 16。
- 菜单“面板”加一项，写成 `("收起或展开左栏", #selector(toggleNav(_:)), "b")`，放在“收起或展开右栏”上面。
- 应用从没存过宽度的老用户：左栏 264、右栏 372，和现在一样。

### P3 自测走查 --walk-columns

`main.swift` 里照 `--walk` 现有做法，加一组步骤（`--walk <文件> --walk-columns`），每步照旧用 `report(...)` 写一行，`report` 那行末尾加上左栏开没开、两个按钮显没显示、返回聊天按钮的左边位置、记住的两个宽度。步骤依次：打开；点卡片；左线拖到 360；右线拖到离右边 500；点收起左栏（`navToggle.performClick`）；收起时右线拖到离右边 400；去设置页；回来点卡片；点展开左栏（`navShow.performClick`）；窗口缩到 900；窗口放到 1280；从菜单动作收起（`toggleNav(nil)`）；再展开。
拖动用发给自己窗口的事件：先 `NSApp.postEvent` 排好 5 个拖动、1 个松手，再把按下交给 `split.mouseDown(with:)`（写法看 `tests/columns_harness.swift` 的 `drag`）；**不移动用户的鼠标**。自测不写用户的设置（`selfTest` 已有判断）。文件开头的参数说明补一行。

## 四、状态表

| 什么时候 | 谁的东西 | 存什么 | 恢复成什么 / 显示什么 |
|---|---|---|---|
| 正常情况：收起、展开 | 整个应用（不分项目） | navOpen | 重开应用还是上次的样子 |
| 正常情况：拖完松手 | 整个应用 | navWidth、rightWidth（只有拖的那一栏会变） | 重开应用还是这个宽度 |
| 窗口太窄、被挤着 | 整个应用 | 不存 | 窗口放宽后回到记住的宽度 |
| 收起着左栏时 | 整个应用 | 左栏宽度仍记着 | 展开回到收起前的宽度 |
| 页面还在加载时收起 | 整个应用 | navOpen | 左栏页面照常加载，展开就看得到 |
| 收起时切项目、点通知切卡 | 整个应用 | 不变 | 左栏保持收起，中间、右栏照常切 |
| 收起时项目浮层开着 | 左栏页面 | 不存 | 浮层先关掉，展开后不再开着 |
| 进设置页 | 整个应用 | 不变 | 右栏照旧收起；左栏保持原来的开或收 |
| 删掉之后 | 不适用 | — | — |
| 退出应用时 | 整个应用 | 已经存好，不用再存 | — |
| 自测 | 测试 | 一律不写 | 不改用户的设置 |
| 以前存的宽度超出新范围 | 整个应用 | 下次拖才覆盖 | 按范围收口后显示 |
