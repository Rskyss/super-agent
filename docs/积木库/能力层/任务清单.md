## 施工中的规矩

- 先写会失败的验收测试，再交 Cursor 施工；测试要守住原有功能（基础层、管家、项目窗口）。
- Cursor 的回执每句都要核。
- 发现和方案对不上：停下来问你，不自己改方案。验收途中冒出的需求外问题先记下，单开一张单。
- 测试和走查都不启动 Claude，不碰你真实的钥匙串和资料夹；真跑只用阿里百炼、Tavily、Codex，要花额度的事先说。

**2026-11-11 Claude 调整：** 第 3 项拆成两张单。68 号单只做能力层页面和本机服务接口；统一叫法单开 68b，等 68 做完再写。原因：两件事碰的文件几乎不重合（叫法要改项目窗口的页面和 Mac 窗口外壳），合在一张单里太大，施工方容易改坏。用户看到的东西不变，68 做完照样停下给用户测。
