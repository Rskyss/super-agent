## 用户原话

- “我要解决的是普通人需要用到很多订阅的能力，把它集成在这一个工具里面，然后通过一个行政……把他们给串起来，解决一个事情。”
- “第一步是接入 CLI，然后从 CLI 里抽离里面的能力，而能力是我后面放到业务流程中的重要积木块。”
- “Claude 的订阅不要参与其中。我只是做了个框架，先把基础层的东西这一层给做好。我举的出图也只是一个例子。”
- “先跟现在的项目团队不接上，可能那块后面得调整，现在就是先把接入各个 CLI 和 API 的能力通用化。”
- “因为这是一个全新的版本，可以跟主要页面不一样，这里设置可以先去掉。第一步，登录页面是让你去绑定一个大模型的 API。绑定成功的话，其实它就是行政。然后你的行政说我需要安装什么 CLI 或者 API。成功了之后，在设置里面可以出现一个最底层的基础层的一块，然后点击它，那么可以进入一个新的聊天，然后进行对它抽取能力。这是第二功能了。我们先把第一个功能先做了，就是让 DeepSeek 来安装 CLI 或者是 API。”

## 整体分几个功能

| 功能 | 内容 | 什么时候做 |
|---|---|---|
| 第一个 | 绑定大模型当行政 → 行政安装 CLI 和大模型 API → 装好的出现在基础层 | **这次** |
| 第二个 | 在基础层点一块，进入一个新聊天，从它里面抽取能力 | 下次 |
| 以后 | 能力拼成业务流程（拖拽画布）、服务类 API（高德这类插头） | 再往后 |

## 第一个功能：你会看到什么

1. **新窗口“积木库”。** 在超级助手里打开，不用先选项目，也没有团队设置。写代码用的项目窗口原样保留，两边互不影响。
2. **第一次打开：绑定大模型。** 页面只做一件事：选服务商（腾讯云、阿里百炼或其他同类），填模型和密钥，点“检测”。
   - 检测通过，就进入和行政的聊天。
   - 检测不通过，用大白话说原因，比如密钥不对、额度用完、地址写错。
   - 密钥存在本机钥匙串里，和项目窗口用的是同一把，不用再填一次。
3. **和行政聊天安装。** 你说“我想装 Codex”或“我想接通义的 API”，行政按下面的顺序办。
   - **CLI：**
     1. 查本机装了没有、什么版本。
     2. 没装，又在核实过的名单里：行政给出官方安装命令，你点确认后由程序执行，过程显示出来。不在名单里：行政给出官网和安装步骤，你自己装，装好告诉它。
     3. 登录：需要弹浏览器授权的，行政告诉你怎么做，这一步你亲手完成。
     4. 行政读这个工具自带的帮助说明，起草一张“接法卡”：用什么命令启动、怎么交代任务、怎么选模型、怎么算干完活。
     5. 程序按接法卡真跑一个小任务来检测。
     6. 检测通过，你点确认，它进入基础层。
   - **大模型 API：**
     1. 行政问清是哪家、用哪个模型，告诉你去哪申请密钥。
     2. 密钥只填在专门的密钥框里，不在聊天里贴，因为聊天内容会发给行政所用的服务商。
     3. 程序发一句话检测。
     4. 通过，你点确认，它进入基础层。
   - 行政起草的接法写错也没关系：检测不过就进不来，行政照着失败原因再改。
4. **基础层页面。** 积木库窗口里有一个页面，列出已经接进来的每一块：
   - 名字，是 CLI 还是 API；
   - 能不能用；
   - 上次检测时间；
   - “检测”按钮；
   - 坏了用大白话说怎么修。

   第二个功能做好之前，点一块只能看详情，不能进聊天抽取能力。

## 已定口径

1. 形态：同一个应用里新开“积木库”窗口，不用选项目，没有团队设置；项目窗口原样不动。
2. 行政：第一次打开就要绑定大模型，绑定成功的这个模型就是行政。
3. 第一个功能装 CLI 和大模型 API（DeepSeek、通义、Kimi 这类，和行政同一种格式）。服务类插头（高德等）以后再做。
4. 安装：只有事先核实过官方安装命令的工具，才由程序执行，执行前要你确认。其他的你自己装，行政带着做。登录由你亲手完成。
5. 接法通用化：每一块用一张接法卡描述，新接一家只多一张卡，不改程序；卡的格式同时适用于 CLI 和 API。
6. Claude 订阅完全不参与。
7. 积木库和现有的项目团队先不接上。
8. 积木库整台电脑共用一份。

## 不做（第一个功能）

- 从基础层抽取能力（第二个功能）。
- 接进基础层后能看到这一块有哪些模型（类似 `/models` 列表），以及干活时选哪个模型、额度不够换哪个：用户 2026-11-09 提出，定为第二个功能（能力层）的第一项。已查：agy、Cursor 有列模型的命令；Codex 帮助里没找到；腾讯云、百炼的模型列表接口没验证过。
- 服务类 API、插头（高德等）。
- 拖拽画布、业务流程。
- 积木库接进项目团队。
- Claude Code 和 Claude 订阅。
- 只能在网页或 App 里用的订阅（不破解，不模拟点击）。
- 定时自动检测、花费统计。

## 怎么算做完

- 用一个全新的资料夹打开积木库：先出现绑定页，用真实的腾讯云或百炼密钥检测通过，进入行政聊天。
- 说“我想装 Codex”：行政查到已安装，起草接法卡，检测通过，你确认后基础层出现 Codex。Cursor、agy 同样走一遍。
- 说“我想接一个大模型 API”：按行政的引导在密钥框填密钥，检测通过后出现在基础层。
- 接法卡故意写错一项：检测不通过，进不了基础层，行政能照着失败原因改对。
- 程序执行安装这一步：用临时环境真实走一次（不碰你现有的工具）。
- 项目窗口和写代码的流程不受影响：真实跑一张卡片照常通过。
- 测试全过，独立复查做过，文档同步。
