## 一、起因

用户在积木库里说“我想装高德地图的 CLI”。行政答：不在名单里，不能编安装命令，你去官网自己装。用户原话：

- “现在这个行政是不是很小白啊，什么都不会啊。之前 Codex、agy 都是预定的，用户新输入一个 CLI，它根本就装不上。其实这是一个流程：先去网上搜，搜完之后装，装完之后去登录。”
- （选 1A）名单外的工具：行政上网查官网，把官网原文的命令和链接给你看，你确认后由程序执行。
- “基础层一定是用户自由组合的，我觉得这里就像一个沙盒，可以把各能力都组合进来，我们做好连接和抽取能力。”

## 二、Claude 查到的情况（2026-11-09）

1. **行政为什么装不上：** 安装命令只能从程序里写死的名单挑，名单上只有 Codex 和 Node（故意定的，防 AI 编出假包名）。上一轮方案写了“名单外的，行政给出官网和安装步骤”，但行政手里没有上网的本事，所以它只能说“你自己去官网”。这是上一轮方案和实际做出来的东西之间的漏洞。
2. **高德确实有官方命令行工具：** 官网 lbs.amap.com/api/cli，安装命令 `npm install -g @amap-lbs/amap-gui`。npm 上这个包 2026-03-27 首次发布，当前 1.0.3，发布者邮箱是阿里巴巴的域名。（上一轮记的“高德只有 MCP、没有 CLI”已经过时。）
3. **高德这个工具和 Codex 不是一类：**
   - 它不会自己干活，是“让 AI 用命令操控地图”的工具：搜地点、规划路线、控制一个弹出来的地图窗口，结果用一段结构化文字返回；
   - 不用登录，要两把高德密钥（Web 端 JS API 的 Key 和安全密钥），以“环境变量”的方式交给它；
   - 现在“接进基础层”的检测是“交代一句话，看它能不能自己新建一个文件”，只认 Codex 这类 AI 助手。高德去检测必然不通过。
4. **高德还官方提供了一份“技能包”**（教 AI 怎么用这个工具），格式就是我们定的 Agent Skills。第二个功能（抽取能力）可以直接借用厂商给的技能包，这一轮不做。

## 三、这一轮要做到什么（你会看到什么）

以“我想装高德地图的 CLI”为例：

1. **行政上网找官方说明。** 行政用基础层里的“联网搜索”积木去搜，找到官网页面，读页面内容，告诉你它找到的是哪个网站、要装的是什么。找不到或拿不准是不是官网，就直说，请你把官网链接贴给它。
   - （2026-11-09 第 0 项实测后用户改：不做带注册，行政只请你把 Tavily 密钥填进接入卡的密钥框；下面这条里“一步步带你注册”作废，免注册用法也不用。）
   - **基础层里还没有“联网搜索”时**（用户 2026-11-09 提出）：行政不先让你去设置里填东西，而是在需要联网的这一刻说“我现在上不了网，要先接一个搜索积木”，然后一步步带你注册 Tavily：给出注册网址、注册时会看到什么、密钥在页面哪里、长什么样（`tvly-` 开头）；聊天里出现接入提议卡和密钥框，你把密钥粘进去，程序真搜一次检测，通过后点“放进基础层”，行政接着刚才的事往下办。
   - 你也可以不注册，直接把官网链接贴给行政，读网页不需要搜索积木。
   - 注册 Tavily 的这几步写死在行政的说明里（施工前 Claude 去 Tavily 官网核对一遍），不靠行政现搜，因为这时它还上不了网。
2. **安装提议卡（网上找来的）。** 和名单里的工具一样出现安装提议卡，但多三样，标“不在核实名单里，来自网上”：
   - 来源网址，网站域名突出显示；
   - “这条命令在官网原文里找到了”：程序自己去打开那一页核对，不信行政的转述；对不上就不出卡；
   - 安装包的底细：npm 上存不存在、第一次发布是什么时候、发布者是谁。查不到这个包就不出卡（防 AI 编的假包名）。
   
   你点“确认安装”，程序执行，过程照旧滚动显示。不提权。
   
   **官网只给“下载脚本直接运行”的（`curl … | sh` 这种，例如 Cursor）：** 程序同样核对命令在官网原文里，然后：
   - 卡上标红一句“这种方式是运行厂商的脚本，脚本做什么程序管不住”，并显示脚本来自哪个网站；
   - 你确认后，程序先把脚本下载下来，再运行它（不把整串命令交给终端去解释）；
   - 只认 `curl … | sh`、`curl … | bash` 这一种写法，脚本地址必须是 https；
   - 脚本要你输电脑密码时停下，告诉你原因，不替你输。
3. **判断它是哪一类，按类办登录。** 行政读工具自带的帮助说明，判断它属于哪一类，再告诉你接下来怎么办：
   - **AI 助手**（Codex、Cursor、agy 这种，交代一句话它自己干活）：要登录的，照旧在终端里亲手登录；
   - **普通工具**（高德这种，给它一条具体命令、它返回结果）：要密钥的，提议卡上出现密钥框，告诉你去哪申请（高德是开放平台控制台）；密钥存进钥匙串，用的时候程序交给工具，聊天里不出现；
   - **大模型 API**：和上一轮一样。
4. **按类检测。**
   - AI 助手：和上一轮一样，让它新建一个文件；
   - 普通工具：行政从帮助说明里挑一条只查不改的命令（高德例：搜一次“天安门”），提议卡上原样显示完整命令，你确认后程序跑一次，看它正常结束、返回了结果；
   - 不通过照旧说原因，行政改，连续 3 次不行就停。
5. **放进基础层。** 基础层左栏照旧列出，每块标出是“AI 助手 / 普通工具 / 大模型 API”。基础层不限定只能放哪几家，你想放什么就让行政去接，这就是“沙盒”。

## 八、先说清楚的风险

1. **“是不是官网”程序判断不了。** 程序能核对“命令确实在这一页上”“这个包真实存在、什么时候发布、谁发布的”，但这个网站是不是厂商官网，最后靠你看域名。高德这次：网页在 lbs.amap.com，包的发布者是阿里巴巴邮箱，能对上；换成别的工具不一定这么清楚。
2. **装一个网上找来的工具，风险比名单里的大。** 名单里的是我事先查过的，网上找来的只过了程序的几道核对。2026 年已经出过多次 AI 代理自动装了假包的事故，所以每次都要你确认，不做“全自动”。
   **“下载脚本直接运行”的风险最大：** npm、Homebrew 至少有“包是谁发布的”可查，脚本没有；脚本运行起来能读你电脑上的任何文件、往任何地方装东西，程序只能做到“确实是官网写的那条”“要电脑密码就停”，管不住脚本本身。官网被人篡改、或行政把仿冒网站当成官网时，这一层也挡不住，只能靠你确认前看清域名。
3. **高德这个工具装的时候要下载一个一百多兆的地图窗口程序**，国内网络可能很慢甚至失败；安装限时 10 分钟。实际能不能顺利装上，没试过。
4. **“普通工具”的检测命令也可能有副作用。** 行政挑的是“只查不改”的命令，但它可能挑错，所以要你看过原文再确认。高德的检测还会花一点高德的免费调用额度。
5. **npm 今年 7 月出的新大版本默认禁止安装时运行脚本**，高德这种要下载地图窗口程序的工具可能因此装不上。你电脑上现在是 npm 10，不受影响；以后升级了会怎样，没验证。
6. **Tavily 注册要你亲手完成。** 行政只能告诉你每一步点哪里，替你点不了；Tavily 网站是英文的。Tavily 以后改版、步骤变了，写死的说明就会过时，要我们跟着改。
