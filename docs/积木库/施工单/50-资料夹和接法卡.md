# 50 号单：积木库资料夹和接法卡

任务清单第 1 项。验收测试：`tests/test_acceptance_50_blocks_store.py`（50 项）。

## 要做什么

新建一个文件 `collab/blocks.py`，只写这一个文件。它管三件事：
- 积木库资料夹在哪；
- 接法卡怎么存、怎么读、怎么检查；
- 检测和安装的记录。

这张单不调用任何外部程序，不碰页面、服务和行政。

## 用户能感受到的

这张单做完，界面上还看不到变化。它是后面所有单的地基：基础层里的每一块，都是一张存在这里的接法卡。

## 接口（测试按这个写，名字和行为不能改）

### 资料夹

- `DEFAULT_ROOT`：`~/Library/Application Support/超级助手/积木库`。
- `home(root=None) -> Path` 按以下顺序取：
  1. 传了 `root` 就用它；
  2. 否则用环境变量 `SUPER_AGENT_BLOCKS_HOME`；
  3. 再否则用 `DEFAULT_ROOT`。

  **只算路径，不建文件夹。**
- 接法卡放在 `<home>/基础层/<编号>.json`，记录放在 `<home>/记录/<编号>.jsonl`。
- 下面所有函数都带 `root=None` 参数，传给 `home()`。

### 报错

`class BlockError(Exception)`，报错文字一律中文，要说清是哪一项不对。测试会检查报错里有没有关键字（例如“编号”“命令”“{prompt}”“密钥”“https”“登录”“文件”“来源”“服务商”“模型”“钥匙串”）。

### `validate_card(card) -> dict`

检查并返回一份**新的**卡（深拷贝，不能改传入的那份），按顺序检查：

1. **不是字典：** 报错，文字里带“接法卡”。
2. **藏了密钥：** 不管哪一层，只要有字段名是 `key`、`api_key`、`apikey`、`secret`、`token`、`password`（不分大小写），或者有字符串里出现 `sk-` 后面跟 16 个以上字母或数字，就报错，文字里带“密钥”。**这一条要先于“不认识的项”检查。**
3. **编号 `id`：** 必须完整匹配 `[a-z0-9][a-z0-9-]{0,39}`，否则报错带“编号”。
4. **类型 `kind`：** 只能是 `cli` 或 `llm_api`，否则报错带“类型”。
5. **只允许这些字段**，多了报错，并列出多出来的字段名：
   - `cli`：`id kind name command run model version_args login_check done_when source note`
   - `llm_api`：`id kind name provider base_url model key_account source note`
6. **名字 `name`：** 去掉空白后不能为空，最长 40 个字，否则报错带“名字”。
7. **来源 `source`：** 缺省填 `clerk`，只能是 `builtin` 或 `clerk`，否则报错带“来源”。
8. **`cli` 类型还要查：**
   - `command`：完整匹配 `[A-Za-z0-9][A-Za-z0-9._-]{0,63}`，不能带路径、空格、分号，不能以横线开头。否则报错带“命令”。
   - `run`：必须是字符串列表，至少有一个元素含 `{prompt}`，否则报错带 `{prompt}`。
   - `run` 里的占位只允许 `{prompt}` 和 `{model}`，出现别的（例如 `{cwd}`）就报错，并写出那个占位。
   - 用了 `{model}`，`model` 就必须是非空字符串，否则报错带“模型”。没用 `{model}` 就不要求。
   - `version_args`：缺省填 `["--version"]`，必须是字符串列表。
   - `login_check`（可选）：`{"args": [非空字符串列表], "ok_words": [非空字符串列表]}`，两个都不能是空列表，否则报错带“登录”。
   - `done_when`：缺省填 `{"file": "连通检测.txt"}`，`file` 只能是文件名，不能带 `/`，不能以 `.` 开头，否则报错带“文件”。
9. **`llm_api` 类型还要查：**
   - `base_url` 必须以 `https://` 开头，否则报错带“https”；
   - `provider` 不能为空，否则报错带“服务商”；
   - `model` 不能为空，否则报错带“模型”；
   - `key_account` 不能为空，否则报错带“钥匙串”。
   - **卡里只存钥匙串账号名，不存密钥本身。**

### 存取

- `save_card(card, root=None) -> dict`：先检查，再写进 `基础层/<id>.json`。用 UTF-8，`ensure_ascii=False`。先写临时文件再改名，写完不留 `.tmp`。同编号直接覆盖。返回检查后的卡。
- `load_card(card_id, root=None) -> dict`：编号不合法就报错。没有这张卡，报错带“没有”。文件坏了或格式不对，用中文报错。
- `list_cards(root=None) -> list`：按文件名排序，只看 `*.json`。好卡原样返回；坏卡返回 `{"id": 文件名, "problem": 中文原因}`，**一张坏卡不能让别的卡消失**。没有文件夹就返回 `[]`。
- `remove_card(card_id, root=None)`：只删卡片文件，**记录保留**。卡片不存在，或者编号不合法（例如 `../基础层`），都报错。

### 预置卡

- `BUILTIN`：键正好是 `codex`、`cursor`、`agy`。预置卡只是模板，**不自动存进基础层**。
- `builtin_card(name) -> dict`：返回检查过的深拷贝，`source` 是 `builtin`；没有这个名字就报错（例如 `claude`）。
- 三张卡的内容照搬 `collab/agents.py` 里现有的命令，模型取 `collab.config.DEFAULT_MODELS`：

| 编号 | command | run | 登录检查 |
|---|---|---|---|
| codex | `codex` | `exec --skip-git-repo-check -s workspace-write -m {model} {prompt}` | `login status`，看到 `Logged in` 算登录 |
| cursor | `agent` | `-p --trust --model {model} --output-format json {prompt}` | `status`，看到 `Logged in` 算登录 |
| agy | `agy` | `-p {prompt} --model {model} --output-format json` | **没有**（agy 没有查登录的命令，不要编） |

（`run` 写成列表，每个空格分开的部分是一个元素。）

### 拼命令

`build_args(card, prompt, model=None) -> list`：
- 先检查卡；`llm_api` 类型报错。
- 返回 `[command] + run 里每个元素替换占位后的结果`。`{model}` 用传入的 `model`，没传就用卡里的。
- **只替换 `run` 模板里本来就有的占位。** 交代本身就算含 `{model}`、引号、分号、`$()`，也原样作为一个参数，不展开，不拆开。
- 这个函数不执行任何东西。

### 记录

- `add_record(card_id, record, root=None) -> dict`：
  - 编号要合法；`record` 必须是字典，并且有字符串 `type`；
  - 里面藏了密钥（规则同上），报错；
  - 补上 `time`（本地时间，形如 `2026-11-08T10:00:00`），追加一行 JSON 到 `记录/<id>.jsonl`；
  - 返回补了时间的那条。
- `records(card_id, root=None, limit=None) -> list`：按写入顺序返回；坏行和不是字典的行跳过；`limit` 取最后几条；没有文件返回 `[]`。
- `last_record(card_id, root=None, type=None)`：最后一条，或者最后一条指定 `type` 的；没有就返回 `None`。
