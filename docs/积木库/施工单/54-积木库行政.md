## 新建 `desktop/clerk/blocks_tools.py`

- `ROLE_FILE`：说明文件的路径（`desktop/clerk/roles/积木库.md`）。`role_text()` 在运行时读这个文件。
- `is_blocks_home(project) -> bool`：判断这个路径是不是积木库资料夹，即解析后等于 `collab.blocks.home()`。
- `TOOLS`：给模型的工具定义，正好 8 个，格式照 `desktop/clerk/tools.py` 的 `TOOLS`：

| 名字 | 参数 | 做什么 |
|---|---|---|
| `scan_environment` | 无 | 调用 `blocks_env.scan(root=资料夹, terminal_path=None, record=True)`，把每一项整理成一行中文：名字、有没有、版本、登录、缺了怎么办 |
| `check_installed` | `command` | 查这个命令装没装、什么版本 |
| `read_help` | `command` | 只运行 `<命令> --help`，限时 10 秒，返回最多 3000 字 |
| `list_blocks` | 无 | 列出基础层里每一块：名字、类型、上次检测结果 |
| `install_options` | `tool` | 列出 `blocks_install.options(tool)`，含编号、说明和原样命令；没有就说“不在核实名单里，要按官网自己装” |
| `propose_install` | `install_id` | 安装提议（见下） |
| `propose_connect_cli` | `template` 或 `card` | 接入 CLI 的提议（见下） |
| `propose_connect_api` | `provider`、`model`、`name`，可选 `base_url` | 接入大模型 API 的提议（见下） |

- `run(project, name, args) -> str`：执行前 5 个只读工具。永远返回中文文字，不抛异常，最多 6000 字。
  - `check_installed` 和 `read_help` 先检查命令名：拼一张假的接法卡 `{"id":"probe","kind":"cli","name":"x","command":命令,"run":["{prompt}"]}`，交给 `blocks.validate_card`。过不了就返回它的中文报错，**什么都不运行**；`bash`、`rm`、带路径或空格的都会被拦在这里。
  - 找命令用 `blocks_env._which(命令, os.environ["PATH"])`，只认完整路径。找不到返回带“找不到”的文字。
  - 运行用 `blocks_env.run_command([完整路径, "--help"], PATH, 10)`。输出先过 `blocks_check._mask` 再截断。
  - `check_installed` 查版本用接法卡默认的 `--version`，只返回像版本号的那一行（可以用 `blocks_env._version_line`）。

## 三种提议（加在 `desktop/clerk/tasks.py`）

做法照现有的 `propose_team_change`：同一段对话里旧的未处理提议标成 replaced；新提议存盘；在对话里追加一行；发 `proposal` 事件；给模型返回一句“已向用户出示确认框……”。参数不对时，返回中文原因，**不生成提议**。

- **`propose_install(conv, args)`**：
  - `install_id` 不在 `blocks_install.INSTALLS` 里，返回带“核实名单”的文字。
  - 合法的话，提议数据带 `kind: "install"`、`install`（编号），外加 `describe()` 的内容：`label`、`command`、`source`、`needs`、`minutes`。
- **`propose_connect_cli(conv, args)`**：
  - 有 `template` 时，用 `blocks.builtin_card(template)`。
  - 有 `card` 时，用传进来的卡，并**把 `source` 强制改成 `clerk`**。
  - 用 `blocks.validate_card` 检查，过不了就返回报错。
  - 同一编号的检测记录里，最近一次通过之后已经连续 3 次不通过，就不提议，返回带“3 次”的文字。
  - 提议数据：`kind: "connect"`、`card`、`name`、`verified`（`blocks.is_verified`）。没核实过的，另带 `preview`（`blocks_check.preview(card)`，就是给用户看的完整命令）。
- **`propose_connect_api(conv, args)`**：
  - 参数里出现任何像密钥的东西（字段名或内容，用 `blocks._has_secret`），返回带“密钥框”的文字，不提议。
  - `provider` 是 `collab.providers.find()` 认得的，地址用它的 `base_url`；`other` 或不认得的，必须带 `https://` 开头的 `base_url`，否则返回带“地址”的文字。
  - 编号由程序生成：`provider` 加模型名，换成小写字母、数字和横线，最长 40 个字，要能通过 `blocks._ID`。`key_account` 是 provider 的编号。
  - 用 `blocks.validate_card` 检查。
  - 提议数据：`kind: "connect_api"`、`card`、`name`、`provider`、`model`。

- **`decide()` 加三种 kind**（取消照旧走通用的那一段）：
  - `install` 确认后返回 `{"ok":True,"state":"confirmed","kind":"install","install":编号,"card":"","repeat":False}`；
  - `connect` 确认后返回 `{... "kind":"connect","card":卡,"approved":preview 或 None}`；
  - `connect_api` 确认后返回 `{... "kind":"connect_api","card":卡}`。
  - 重复确认返回同样的结果，`repeat` 为 True。
- **`event_from_proposal()`** 把三种新提议需要显示的字段带上：上面提议数据里的那些字段原样带上。

## 改 `desktop/clerk/desk.py`（只改这几处）

1. `_tools_for(conv)`：`is_blocks_home(conv.project)` 时返回 `blocks_tools.TOOLS`。
