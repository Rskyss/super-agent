# 方案：右栏显示小修

> 状态：Claude 按 2026-11-20 外出授权自批（用户出门前对齐的清单第 2 项）。判大小：小（两个文件、几十行）。

## 一、你会看到什么变化

1. 写代码前程序先跑新测试的那一两分钟，右栏“跑测试”格转圈并计时，顶部写“程序在写代码前先跑一遍新测试”，不再是“程序在安排下一步”、哪格都不转（11-19 21:37 你截图问“没有动静”那次）。
2. 顶部一句话、卡片标题下那一行不再露出“调度员”（干活的 AI 自己说到这个词时）。
3. 复查员写“结论:不通过”（半角冒号）、又碰上退满加全部测试没过而停下时，复查格不再亮绿勾。

## 二、病根和改法

- 1：先红检查只在跑完后记一条结果，跑的时候右栏无从知道。改法跟“全部测试”同构：开始时记一条“先红开始”，右栏看到有开始没结果、程序还活着，就让跑测试格转圈。
- 2：右栏别处都过了一遍“把调度员换成人话”，这两处漏了。补上同一个换词。
- 3：跑卡程序认半角冒号，右栏只认全角。右栏改成两种都认。

## 三、撤出的一项

出门前清单里的“待验收时写方案格仍显示正在做的动作”撤出这张卡：老测试特意让最终核验时写方案格转圈（守“任何时候都要有一步在转圈”），改成“方案已定”就没有格子转圈了，要连带重新设计哪一格显示最终核验。仍记在以后再修，留给你回来定要不要改。

## 四、影响面

只改右栏显示和多记一条流转；跑卡流程不变。试改已在相关老测试 778 项上全过。
