# 施工单 右栏显示小修：先红检查转圈、不露旧称、半角冒号不亮绿勾

> 依据 [方案-右栏显示小修](方案-右栏显示小修.md)（Claude 按 11-20 外出授权自批）。
> 写给开发助手的施工方。项目就是开发助手这个仓库。**验收测试已经写好**（`tests/test_panelfix_acceptance.py`），施工方**不许改**；写测试的只**补充**，写进新文件 `tests/test_panelfix_extra*.py`。**只按本施工单做，没要求的功能、写法不要自己加。**

## 一、要做什么（一句话）

右栏三处显示修正：写代码前程序先跑新测试的那一两分钟，“跑测试”格转圈计时、顶部写“程序在写代码前先跑一遍新测试”；顶部一句话和卡片标题下那一行不再露出“调度员”；复查员用半角冒号写“结论:不通过”时，复查格不亮绿勾。

## 二、允许改哪些文件

- `collab/dispatch.py`（只改 `_red_check_one` 开头那一处）
- `desktop/view.py`
- `tests/test_panelfix_extra*.py`（写测试的新建）

**不许改**：`tests/test_panelfix_acceptance.py`，以及上面没列的任何文件。

## 三、具体做法

### P1 先红检查时转圈

- `collab/dispatch.py` 的 `_red_check_one` 一进来先记一条流转：`kind="先红开始"`、`src="程序"`、`step=step`、`summary="写代码前先跑一遍新测试，确认它们现在真的不过"`、`reply_to=reply_seq`。其余不动。
- `desktop/view.py` 的 `card_view`：在算 `testing` 的地方，取最后一条 `先红开始` 或 `先红检查`；最后一条是 `先红开始`、没有正在干活的人（`open_ev` 为空）、没中断（`interrupted_run` 为假）、卡不在终态，就算“先红检查在跑”：
  - `check` 格：`active`，说明写“写代码前先跑一遍新测试”，`live=True`，`elapsed` 从那条 `先红开始` 的时间算起；
  - 顶部一句话（`now_text`）：“程序在写代码前先跑一遍新测试”，`tone="run"`，排在 `testing` 那一支前面。

### P2 不露“调度员”

- 没建卡、只有聊天时（`card_view` 里返回 `card={"id": "调度中", ...}` 的那处），`now` 里的 `text` 也过一遍 `_plain`。
- 有卡时 `view["now"]["detail"]`（标题下那一行实时进度）过一遍 `_plain`。

### P3 半角冒号的“不通过”

- `card_view` 里复查格判断 `failed` 时，“结论：不通过”开头的判断改成全角、半角冒号都认（`结论[：:]` 后面可以有空白，再跟“不通过”）。

## 四、不做什么

不改记录的字段名和老记录；不改跑卡流程本身（除了多记一条“先红开始”）；不改面板脚本和样式；不动写方案格在待验收时的显示。
