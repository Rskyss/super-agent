# 施工单 第三批 D1：跑卡程序和右栏的显示、说法

> 依据 [方案-第三批](方案-第三批.md)（Claude 按授权自批）、[需求共识-第三批](需求共识-第三批.md)（用户已批）。
> 写给开发助手的施工方。项目就是开发助手这个仓库。**验收测试已经写好**（`tests/test_batch3_d1_acceptance.py`），施工方**不许改**；写测试的只**补充**，写进新文件 `tests/test_batch3_d1_extra*.py`。
> 第五节那几项老测试 Claude 已在建卡前按新口径改好，**不许再改**。**只按本施工单做，没要求的功能、写法不要自己加。**

## 一、要做什么（一句话）

右栏、流转记录、停下说明里不再出现“调度员”；测试超时停下后接着跑只重跑测试；写方案格只写写方案的事；“已放进项目”不带分支名；用量小字加说明；Claude 亲自做的卡不出按钮；被限流停下说“服务限流”。

## 二、允许改哪些文件

- `collab/dispatch.py`
- `collab/phase.py`
- `collab/merge.py`
- `collab/cli.py`
- `desktop/view.py`
- `desktop/static/panel.js`
- `tests/test_batch3_d1_extra*.py`（写测试的新建）

**不许改**：`tests/test_batch3_d1_acceptance.py`、第五节列的老测试，以及上面没列的任何文件。

## 三、具体做法

### C1 不再出现“调度员”
- **流转记录里的 `src`、`dst` 字段不改名**（程序内部靠它们找人，老卡也要对得上）；只改用户看得见的文字。
- `desktop/view.py`：
  - 加一个 `_plain(text)`：把显示用的文字里“需要调度员看看/处理/介入/看原因/看”换成“需要你看看”，“调度员备好了”换成“程序备好了”，剩下的“调度员”一律换成“程序”。凡是交给页面的 summary、detail、顶部一句话、交接列表的 from/to/summary，都过一遍 `_plain`（老卡记录里的旧说法也就看不到了）。
  - `_label`：角色是“调度员”时显示“程序”。
  - 左边聊天那几句 `f"调度员 {disp_who} ..."` 去掉“调度员 ”前缀（例：“Codex 正在干活：运行 npm test”）；“调度员在和你对齐需求、写方案…”“方案已批准，等调度员开工”“需要调度员介入：…”“调度员在安排下一步”“可让调度员继续/接着跑完”“等调度员最终核验完”等，改成不提调度员的大白话（如“在和你对齐需求、写方案，等你批准方案”“方案已批准，等开工”“卡停下了，等你处理：…”“程序在安排下一步”“可以点‘接着跑’继续”“等最终核验完”）。
- `collab/dispatch.py`、`collab/phase.py`：写进 summary、say 的“需要调度员看看/处理/看/看原因”改成“需要你看看”；“调度员备好了交接资料”改“程序备好了交接资料”。给工具的交代（prompt）里的“你是调度员”**不改**（工具看不到界面）。

### C2 测试超时停下后，接着跑只重跑测试
- `collab/dispatch.py` 判断“代码已写好、跳过写代码”（`dev_already_done`）那段：之后的判定/页面检查结果是 `TIMEOUT`（超时）的**不算**“测试没过”，照样跳过写代码、直接重跑测试。其他没过（没过、跑不起来）照旧重派写代码的。

### C3 复查停下红叉挂复查格（11-18 已修一半，补齐）
- `desktop/view.py`：停下原因是复查不通过（`cause` 为“复查不通过”、复查格式看不懂、退满停下）时，复查格（`rev`）为 `fail`，写方案格不挂红叉。验收测试里这条现在已经过，保持住。

### C8 写方案格只写写方案的事
- `desktop/view.py` 写方案格（`disp`）在待验收、已合并时写“方案已定”（不再写“已向你汇报”“已放进项目”）。

### C9 “已放进项目”不带分支名
- `collab/merge.py` 放进项目成功那条“合并”记录：summary 固定“已放进项目”，分支名写进全文（`text=f"已放进 {branch} 分支"`）；台账那句照旧可以带分支名。

### C10 用量小字说明
- `desktop/static/panel.js`：用量的鼠标提示里加一句“每答完一轮才更新一次”。

### C11 Claude 亲自做的卡
- `collab/cli.py` 的 `new-card` 加开关 `--by-claude`：建卡后在卡片目录写 `Claude亲自做.json`（内容 `{"by": "Claude"}`）。
- `collab/phase.py` `card_phase`：有这个文件、且卡没有已合并或已放弃时，返回 `{"code": "by_claude", "label": "Claude 亲自做", "tone": "run", "needs_you": False, "detail": "进度看下面的流转记录", "actions": []}`。

### C12 被限流停下说“服务限流”
- `collab/dispatch.py` `_worker_failed`：回复原文里有 `429` 或 `Too Many Requests` 时，停下说明写“{角色}（{工具}）被服务限流（请求太多）停下了，建议在团队设置{换模型}或过一会儿再点“接着跑””；不说“模型没回话”。换模型建议照旧用 `_suggest_model`。这个判断放在“模型没回话”判断**之前**。

## 四、不做什么
