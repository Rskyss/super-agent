## 一、要做什么（一句话）

用户粘贴的话里写明了“要做什么 / 不做什么 / 怎么算做完”时，程序照用户写的填进确认框各格（模型漏填、把整段塞进“要做什么”都纠正过来）；卡片标题如果是“按施工单做：路径”这种，换成施工单文件第一行标题；行政不再说“读不了施工单”；右栏“写代码”的进度条只数这张卡开工时还没过的那几项；左栏已完成的卡加一行完成时间。

## 三、具体做法

### C5、C6 认全粘贴的话（`desktop/clerk/tasks.py`）

- 加 `_fields_from_text(text) -> dict`：从一段文字里认出标了名字的几格，返回 `{"title"?, "do"?, "not_do"?, "done_when"?}`，没认出的不放。认两种写法：
  1. 行首“标题 / 要做什么 / 不做什么 / 怎么算做完”加中文或英文冒号，冒号后面到下一个标签行之前（含换行）都是这一格；
  2. Markdown 标题行（`#` 到 `###` 开头）写这几个名字，下面到下一个标题行之前是这一格。
  标签前后的 `**`、空格忽略；内容去掉首尾空白，空的不算。
- `propose(conv, arguments)`：先取这段对话里**最后一条用户的话**（`conv.messages` 里 role 为 user 的最后一条）跑 `_fields_from_text`。认出的格子**照用户写的覆盖**模型给的（用户写的为准）；没认出的格子照用模型给的。然后再按原来的规矩查缺：还缺才回“还缺：…，先问用户”。
- 用户没写任何标签时，一切照旧。

### C7 卡片标题用施工单标题（`desktop/clerk/tasks.py`）

- 在 `propose` 里查缺之前：用 `collab.planner.existing_orders(conv.project, 标题 + "\n" + 要做什么 + "\n" + 用户最后一句)` 找引用的施工单；找到、且标题以“按施工单”开头或标题里带“/”或“.md”时，把标题换成第一个施工单文件里第一行 `# ` 标题的文字（去掉 `#` 和首尾空白）；文件读不了、没有 `# ` 标题就保留原标题。

### C5 说法（`desktop/clerk/desk.py`）

- `ROLE` 里“不用先读那个文件（写方案时会去读）”后面加一句：“施工单你不用读，也别说读不了；只说写方案时会读。”

### C13 进度条只数本卡开工时没过的那几项

- 加一个认测试名字的小函数（放 `collab/progress.py`，`dispatch.py` 引用）：从测试输出里找 `FAIL: 名字 (括号)`、`ERROR: 名字 (括号)` 行，统一成“括号里去掉末尾的 .名字 后 + . + 名字”（老版 Python 括号里是 `模块.类`，3.12 起是 `模块.类.名字`，两种都要认成同一个 `模块.类.名字`）。
- `collab/dispatch.py` `_red_check_one`：结果是“没过”时，把输出里认出的没过的测试写进卡片目录 `开工前没过的测试.json`（`{"tests": [...], "step": 步骤}`，覆盖上一份）；“过”、跑不成时不写。
- `collab/progress.py` `ProgressJob.compute`：卡片目录有这份文件、且 `tests` 不空时：照原样跑本卡命令（每段都跑），收集每段输出里没过的测试名；`total` = 文件里的个数，`passed` = 文件里有、这次没出现在没过名单里的个数，返回里加 `"own": true`。导入就报错、超时、跑不起来照原来的报法。没有这份文件时完全照旧（不带 `own`）。
- `desktop/static/panel.js` `PanelCore.progressText`：`own` 为真时文字写“本卡要做的 N 项，已过 x 项”（`pct` 照算）；否则照旧“通过 x/y”。

### C14 左栏卡片加一行完成时间

- `desktop/view.py` `list_cards`：每张卡多给一个 `finished`（秒数）。已合并：最后一条“合并”记录的时刻；已放弃：最后一条记录的时刻；其他状态 `None`。时刻用记录里的 `ts`；老记录没有 `ts` 只有钟点 `time` 的，按本机时间换成秒数（照 `view.py` 里 `_when` 的办法）。
- `desktop/static/nav.js`：`NavCore` 加 `finishLine(c, now)`：已合并写“完成于 ”+时间，已放弃写“放弃于 ”+时间，时间一律写完整的年月日和时分，例如“完成于 2026-11-19 17:48”（用户 11-19 要求加年月日；不用 `timeLabel` 的今天/昨天写法）；没有 `finished` 或别的状态返回空字符串。`cardRow` 里在“已完成 · 返工 N 次”那行下面再加一行显示它（空就不加）。
- `desktop/static/nav.css`：新加那一行和上一行同样的小字、同样的颜色，不挤压标题。
