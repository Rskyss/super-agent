# 拆解方案

> 照施工单 docs/走查截图/施工单-卡A.md 生成，没有让 AI 再写一遍。

## 要做什么（一句话）
施工单写了“走查命令”的卡，写代码的交活、本卡测试过了以后，程序自动跑走查命令：每次给它一个新的放截图的文件夹，跑完读步骤清单，截图记进卡片流转；走查没过、没留下截图、清单不对，都像测试没过一样退回写代码的；复查员的交代里列出这次交活的每一步截图和设计图。本单不改右栏和卡片界面（走查刚过或走查没过时右栏照现有逻辑显示走查结果，全部测试跑完后照旧显示全部测试结果，11-21 用户定砍掉末尾拼接和“正在走查”转圈）。没写走查命令的卡和现在完全一样。

## 拆成几步，每步做什么、产出什么
1. P1 照施工单生成方案时摘出走查命令（`collab/planner.py`）
2. P2 开工时自己读走查命令（`collab/cli.py`）
3. P3 跑走查（`collab/dispatch.py`）
4. P4 复查员看截图（`collab/dispatch.py` 的 `_review_prompt`）

施工单写了“走查命令”的卡，写代码的交活、本卡测试过了以后，程序自动跑走查命令：每次给它一个新的放截图的文件夹，跑完读步骤清单，截图记进卡片流转；走查没过、没留下截图、清单不对，都像测试没过一样退回写代码的；复查员的交代里列出这次交活的每一步截图和设计图。本单不改右栏和卡片界面（走查刚过或走查没过时右栏照现有逻辑显示走查结果，全部测试跑完后照旧显示全部测试结果，11-21 用户定砍掉末尾拼接和“正在走查”转圈）。没写走查命令的卡和现在完全一样。

## 明确不做什么
不改右栏界面（`desktop/view.py`，全部测试跑完后不在末尾拼接走查结果，也不做“正在走查”的转圈）、不改卡片界面（显示截图是卡 B 的事）、不改走查工具和它的测试（环境问题含缺 playwright/打不开 Chrome/本机拒绝绑定 127.0.0.1 退出 127，副本改坏后台退出 1，写施工单的角色开工前已改好）、不改 agents/ 下的规则和交代、不改命令行 --page-check 的老用法、没有引用施工单的卡不支持走查、不把截图搬进 docs、不改全部测试和测试判定的规矩、不清理旧的走查截图、不给“走查脚本写错”另做处理流程。
