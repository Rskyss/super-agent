3. **CARD-022 以后再修（2 条）**：两次不同走查失败输出相同“走查完了”可能被误判同类错误转人工；开发员首轮超时后有通过走查时复查员可能收不到截图。

5. **换电脑测试条件**：全部测试中含浏览器走查自检，要求本机已安装 Chrome 并为运行用 Python 安装了 playwright（缺了会直接报错不跳过，换电脑需重装）。
