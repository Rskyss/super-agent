## 五、踩过的坑（接手时注意）

- 后台盯 Codex 复查的监控别用 `grep "^exit="`、`ERROR:`、`429` 判结束或报错：Codex 跑测试、读代码时输出里就有这些字，误报过三次。可靠的办法：看 `codex exec -o <结论文件>` 写出来没有、进程还在不在。

- 流转记录的 `text` 字段存的是全文文件位置（`流转/xxx.md`），测试里要读那个文件。
- 项目说明在 `docs/项目说明.md`；`--dev-tool` 只认 cursor/codex/agy/qwen/tencent。
- 用 heredoc 跑带长中文的 python 脚本时出过一次编码错误、整段没执行（只有后面的追加生效），改完要核对文件真的变了。
