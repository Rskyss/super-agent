## 二、DSH 服务与设置接线方法

- **`useSessions` / `useWorkspaces`**：从 DSH `ui-slots` 自动注入的 `GlobalStandardProps` 接入（通过 `PropsRuntime<'sidebar'>` 接收 `props.useSessions` 与 `props.useWorkspaces`），不再依赖原 `ui-sidebar` 子槽。
- **应用版本号与首配锁**：版本号通过 DSH 构建内联环境变量 `process.env.DSH_CLIENT_VERSION` 读取（未注入时不展示）；`useSetupLocked` 沿用现有 `onboardingStore` 订阅状态。
- **左栏宽度与窄屏收起复用**：复用 `ui-layout` `AppFrame` 对 `sidebar` 槽位下发的 `{ collapsed, width, drawer }`，并在 `shell.leading` 注册 `SidebarLeadingOpener` 调用 `ui.layout.toggleSidebar()`，保证窄屏抽屉或桌面收起后可重新展开。
- **打开 DSH 设置积木库**：在 `SidebarSlotView` 声明 `children: { 'sidebar.settings': { kind: 'single', scope: 'root' } }` 并将 `renderSlot('sidebar.settings', { wide })` 隐形挂载于底部，使 `ui-settings-general` 的 `SettingsRoot`（含 `createPortal` 到 `document.body` 的设置弹框与 `Cmd+,` 快捷键）保持运行；同时注册 `priority: -100` 的 `settings.launcher` 桥接器覆盖原生账号菜单，捕获 `props.openSettings`，在点击左栏底部 `⚙ 设置` 时调用 `openSettings('superagent-blocks')` 直达“积木库”页（不可用时由 `SettingsPanel` 自动回退至首项）。
