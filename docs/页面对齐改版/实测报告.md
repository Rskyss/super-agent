# 页面对齐改版 · 实测报告（11-16，约 1 小时）

> 问题：能不能把 DSH 自带的页面换成我们自己的页面（按设计图搭），底层的对话、调模型照常用？（用户定方向 A：页面结构全按我们的图自己搭，借 DSH 底层和颜色、按钮这些基础零件。）
>
> 做法：写了一个很小的试验插件（`实测/试验插件/`），只装进临时副本，不碰现有代码、不碰你在用的超级玩家。用本机假模型服务，不花额度。测完已拆掉、测试钥匙串记录已清。

## 结论：可行

| 想知道的 | 结果 |
|---|---|
| 左栏能不能整块换成我们的 | **能**。关掉 DSH 自己的左栏，我们的左栏（品牌 + “新会话” + 对话/任务 + 设置）直接占位；点我们的“新会话”能开新对话。截图 `实测/01-…png` |
| 右栏能不能换成我们的 | **能，但 DSH 右栏不能关**：DSH 的聊天部分离不开它的右栏服务，关掉整个应用起不来。办法是 DSH 右栏留在底下，我们的右栏按优先级盖上去——实测我们的右栏出来了、应用正常 |
| 会话顶上的标题栏能不能换 | **能**。我们的标题栏盖上后，DSH 的“对话 / 轨迹 / 任务轨迹”那排标签没了。截图 `实测/02-…png` |
| 中间放我们自己的整页（首次配置、任务总览这类） | **能**。现在的“任务总览”就是我们自己的整页，放在中间区域，早已在用 |
| 图上没有的 DSH 东西能不能关掉 | **能，改一行配置**：模型选择、权限（“工作区内修改”）、点赞点踩、每秒字数统计都关掉了，聊天照常。不删代码，改回来就恢复 |
| 底层还能不能用 | **能**。从我们的左栏开新对话、发消息，DSH 照常调模型、流式回复、显示在中间 |

## 换法总结（给后面施工看）

- **整套“外框”（左、中、右三栏的宽度、拖拽、收起）用 DSH 的**——它只管几何尺寸，不管里面放什么，设计图也是三栏。
- **三栏里面的东西全是我们的**：左栏、右栏、中间的标题栏、中间的整页（首次配置、首页、任务总览）、输入框上下的条，都由我们的插件放进去，盖住或替掉 DSH 的。
- **聊天消息本身（一问一答、流式显示、工具调用折叠）先用 DSH 的**——设计图里的对话样子和 DSH 很接近，自己重做量大、收益小；有和图不一样的细节再一处处盖。
- **DSH 自带、图上没有的**：能关的用配置关（记进“已藏清单”）；关不掉的（比如右栏服务）就用我们的盖住。

## 还剩的、实测没覆盖的

- 每条回复下面的“复制、分享、用量”、“已完成，用时 1 秒”这行、输入框下面的“1 轮 1 步 · 缓存命中”：来自 DSH 聊天和输入框内部，实测没去动；按同样办法（关配置或盖住）应该能处理，**没验证，施工时逐个核对**。
- 浅色 / 深色：试验插件用的是 DSH 的颜色变量，跟着系统走没问题；照图的深色细节施工时对。
- 设置页里 DSH 的那些页（通用、模型、内置插件……）能不能逐个关：没测。
