> 依据 [方案](方案.md)（用户 11-20 批准）。照规则包《施工单怎么写》写，第一次用新写法。
> 写给开发助手的施工方。项目就是开发助手这个仓库。**验收测试已经写好**（`tests/test_rightfix_acceptance.py`、`tests/rightfix_page_check.js`，测试数据在 `tests/fixtures/card019/`），施工方**不许改**；写测试的只**补充**，写进新文件 `tests/test_rightfix_extra*.py`；要补实跑页面的检查，写进 `tests/rightfix_extra*.js`，**同时**在 `tests/test_rightfix_extra*.py` 里加一条用 node 调用它的测试（照 `test_rightfix_acceptance.py` 最后一条的写法），否则验收命令跑不到它。**只按本施工单做，没要求的功能、写法不要自己加。**

## 一、要做什么（一句话）

右栏每一步的 token 用量另起一行；卡停下时右栏顶部只写“卡住了”和按钮，原因全文放进中间卡片标题下那一行（默认收起一行、可展开）；由 Claude 接手修好的卡，复查格变绿勾并写明，流程里多一格“Claude 接手”，本卡合计下面写完成时间。

## 三、具体做法

动手前先看第四节状态表和第五节原有行为清单。

### P1 token 另起一行（panel.js、panel.css）

- `PanelCore` 里拆出两段：`statusText(s, since)` 只拼轮次、用时、动静（就是现在 `metaText` 前半段的规则）；`usageText(s)` 只拼用量（就是现在 `metaText` 里 `s.tokens` 那段，字一样）。
- `metaText(s, since)` 保留，改成把这两段用“ · ”接起来（输出和现在一模一样，老的函数测试不动），用在每一步按钮的 `aria-label` 里：`角色 工具，状态和用量，看交接`。
- 每一步按钮里在 `.k` 后面加一个 `<span class="u"></span>`：`.k` 用 `statusText`，`.u` 用 `usageText`；首次绘制和定时刷新（`tick`）都用 `statusText` 写 `.k`，`tick` 不动 `.u`。`.u` 没内容时不占位。
- 样式：`.u` 和 `.k` 一样小字、另起一行。

### P2 停下时右栏顶部只留按钮（panel.js）

- `phaseHint`：阶段是 `blocked`（卡住了）时只写“卡住了（原因在中间卡片标题下）”，不拼 `detail`。别的阶段照旧“标签 · 说明”。

### P3 中间卡片标题下那一行收起、展开（chat.js、chat.css）

- `#cardNow` 默认收起成一行（class `fold`）；放不下一行时，后面出一个按钮“展开”，点了去掉 `fold`（加 `open`）看全文，按钮变“收起”。判断放不下照现成的 `cardFoldButton` 做法（比较 `scrollHeight` 和 `clientHeight`）。
- 每 3 秒刷新那一行时只换文字，**不改**收起还是展开；文字变短放得下了，按钮藏起来。
- 换一张卡（`openCard`）回到收起；关掉卡（`hideCard`）按钮一起藏起来。
- 样式：`#cardNow.fold` 一行截断（现在是 3 行），`#cardNow.open` 不截断。

### P4 记接手的命令（cli.py）

- 新命令：`python3 -m collab.cli takeover <项目> <卡号> --changed N --reviews N --later N --note "一句话"`。
- 卡片文件夹不存在：报错退出（退出码不是 0），什么都不记。
- 存在：在卡的流转里记一条，`kind` 是“接手”，`src` 是“Claude”，`summary` 是 note，另带 `changed`、`reviews`、`later` 三个整数（用现成的 `collab.flow.record`）。打印一句“已记下”。

### P5 右栏数据（view.py）

- **复查格**：卡片流转里有“接手”记录、而且它在最后一次复查结论之后，复查格原来是红叉的，改成绿勾，说明在原来的字后面加“，已由 Claude 接手修好”（CARD-019 显示“复查退回 4 件，已由 Claude 接手修好”）。没有接手记录的，一点不变。
- **Claude 接手一格**：有“接手”记录时，在“复查”和“确认”之间插一格：`key` 是 `takeover`，`role` 是“Claude 接手”，`who` 是“Claude”，状态 `done`，说明“改了 N 处 · Codex 复查 N 轮 · N 条记进以后再修”（取最后一条接手记录）。没有接手记录的卡还是 7 格，顺序不变。
- **完成时间**：卡是“已合并”时，视图里多一个 `finished_at`，值是最后一条“合并”记录的时间（秒）；别的状态没有这个字段（或为空）。

### P6 右栏显示 Claude 接手一格和完成时间（panel.js、panel.html）

- 右栏现在固定搭 7 格；改成搭 8 格，`renderFlow` 只画 `v.stations` 有的那几格，多出来的那格藏起来（换到只有 7 格的卡时也要藏回去）。
- panel.html 里 `#tokenTotal` 后面加一行 `<p class="token-total" id="doneAt" hidden></p>`（写在页面里，不在脚本里临时建：老测试的页面替身只认页面里写好的元素）。
- `#doneAt` 写“完成于 月-日 时:分”（按电脑本地时间，两位数补零，如“完成于 11-20 13:00”），只在有 `finished_at` 时显示；没有合计 token 但有完成时间时也显示；换到没有 `finished_at` 的卡要藏回去。

## 四、状态表

| 什么时候 | 谁的东西 | 存什么 | 显示什么 |
|---|---|---|---|
| 正常：卡停下、第一次打开这张卡 | 中间卡片标题下那一行 | 不存（只在页面里） | 收起成一行；放不下才有“展开” |
| 点了“展开”后，3 秒刷新到了 | 同一张卡 | 页面记住“这张卡展开着” | 还是展开，文字换成最新的 |
| 展开着，换看另一张卡 | 新卡 | 清掉 | 新卡回到收起 |
| 展开着，关掉卡回主对话 | — | 清掉 | 那一行和按钮都藏起来 |
| 展开着，刷新后文字变短、一行放得下 | 同一张卡 | 照旧 | 按钮藏起来，文字照常显示 |
| 页面还在加载这张卡的数据 | — | — | 那一行先藏着（现在就是这样） |
| 右栏从有接手的卡（8 格）换到没接手的卡（7 格） | 右栏 | — | 第 8 格藏起来，不留空白格 |
| 接手命令记了两次 | 卡片流转 | 两条都留 | 右栏按最后一条显示 |
| 接手之后又有一次复查退回 | 卡片流转 | — | 复查格回到红叉（接手记录不在最后一次复查结论之后），Claude 接手那格照常显示 |
| 右栏从已完成的卡换到没完成的卡 | 右栏 | — | “完成于”那行藏起来 |
