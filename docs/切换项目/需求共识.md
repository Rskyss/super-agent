# 需求共识：左下角一键切换项目

> 2026-11-19 用户提出，状态：用户已确认（11-19；同日补口径 7）
> 大小判定：大需求（同时动 Mac 窗口外壳和左栏页面，跨模块），走三份文档。

## 用户原话

> 我这个地方是不是可以去切换我的项目目录的？现在我需要到上面菜单去调整才可以……点出来之后就有我之前的历史记录，然后也可以添加，可以灵活地切换。不同的项目里面有不同的对话和卡片。

## 需求大白话

1. 左栏左下角现在只显示项目名（如“开发助手”），改成可以点的，名字后面带一个向下小箭头。
2. 点开向上弹出一个浮层，样子照 Codex 的“选择项目”（用户 11-19 给的截图）：
   - 最上面一个“搜索项目”框，打字就按项目名筛；
   - 中间是项目列表，每行一个文件夹小图标加项目名，最近用的在最上面，放不下可以上下滚；当前项目高亮并打勾；
   - 最下面一条分隔线，下面是“＋ 添加项目”，弹出选文件夹（系统窗口里也能新建文件夹），选好直接切过去；
   - 点浮层外面或按 Esc 关掉。
3. 点某个项目就切过去：左栏对话列表、等待处理、右栏卡片全部换成那个项目自己的。
4. 顶部菜单“文件 → 打开项目… / 最近打开”保留，两个入口效果一样、列表一样。
5. **每个项目记住“上次停在哪”**：切回一个项目时，回到离开时打开的那段对话或那张卡，输入框里没发出去的字也还在。

## 已查到的现状（Claude 核实过）

- 顶部菜单本来就能切项目，最近 10 个也已经记着，这次主要是**在左下角加一个更顺手的入口**，复用现有切换动作，不另造一套。
- 每个项目的对话、卡片本来就存在各自项目文件夹里，切换后自然分开。
- 跑卡是单独在后台跑的，切项目不会停掉它，所以口径 1 基本是现成的；**要实测确认**：切走再切回，进度、计时、结果都还在。
- 现在切回项目：左边会接上最近一段对话（多数时候就是离开时那段），但选中的卡片会清空、没发的字会丢——这是口径 7 要补的（T0 时实测确认）。
- 已查（代码层面）：行政回话在后台写完并存下来，切走不会丢；待实测确认。

## 怎么算验收通过

1. 左下角点项目名能弹出浮层：搜索框、带文件夹图标的项目列表（当前项目打勾、能滚动）、底部“＋ 添加项目”；搜索能按名字筛；点外面或 Esc 能关。
2. 点另一个项目：左栏对话、等待处理、右栏卡片都换成那个项目的，窗口标题跟着变。
3. “＋ 添加项目…”选一个新文件夹能切过去，并出现在左下角和顶部菜单的列表里。
4. 项目 A 有卡在跑时切到 B 再切回 A：卡还在跑或已正常跑完，进度不丢。
5. 行政回话途中切走再切回：回复不丢。
5b. 在项目 A 打开某段对话、输入框打了几个字没发，切到 B 再切回 A：还是那段对话，字还在；在 A 打开某张卡再切走切回：还是那张卡（看卡时输入框的字不记，T0 写施工单时 Claude 定）。
6. 用户在真实窗口里亲手点一遍，和上面一致。
