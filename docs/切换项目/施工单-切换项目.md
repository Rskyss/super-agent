## 三、具体做法

### P1 规则层（纯函数，验收用 node 测）

- `nav.js` 的 `NavCore` 加：
  - `projectName(path)`：取最后一级文件夹名，末尾斜杠忽略。
  - `projectItems(paths, current, query)`：返回 `[{name, path, current}]`。顺序照 `paths`；重复路径只留第一个；`current` 不在 `paths` 里就补在最上面；`paths` 为空/非数组当空。`query` 去掉首尾空白后为空就全给；否则只按 `name` 不分大小写“包含”筛（不按路径筛）。
- `chat.js` 的 `ChatCore` 加 `restorePlace(threads, saved)`，返回 `{open, draft}`（`open` 为对话编号或 `null`）：
  - `saved.thread` 非空且在 `threads` 里：`{open: saved.thread, draft: saved.draft || ""}`；
  - `saved.thread` 为空、`saved.draft` 去空白后非空：`{open: null, draft: saved.draft}`（回到“新对话”带草稿）；
  - 其他（没有记录、记录的对话已删、全空）：`{open: threads[0] 的 id 或 null, draft: ""}`。
  - 记得加进 `ChatCore` 末尾的 return 对象。

### P2 左下角按钮和浮层（nav.html / nav.js / nav.css）

- `<footer class="foot">` 里，把 `<span class="proj" id="proj"></span>` 包进 `<button class="proj-btn" id="projBtn" type="button">`，按钮里在名字后面加一个向下小箭头（内联 svg）。`id="proj"` 保留（后台刷新时往里写名字的老代码不动）。“团队”按钮不动。
- 在 `<aside>` 里（footer 前）加浮层 `<div class="proj-menu" id="projMenu" hidden>`：
  - `<input id="projQ" placeholder="搜索项目" aria-label="搜索项目">`
  - `<div id="projList"></div>`：每项一个 `<button class="proj-item">`，内容是文件夹图标（内联 svg）＋项目名；当前项目加 class `on` 并在右边显示 ✓；没有结果时显示“没有匹配的项目”。列表区最高约 7 行，超出可滚动。
  - 一条分隔线，下面 `<button id="projAdd">` 内容“＋ 添加项目”。
- 样式（`nav.css`）：`.proj-btn` 无边框、鼠标移上去变亮（参照 `.gear:hover`）；`.proj-menu` 绝对定位在左下角按钮上方、宽度约等于左栏宽度减两边各 8px、深色圆角卡片（参照 Codex 截图：`background` 比左栏略亮、`border-radius` 12px、细边框、阴影）；`.proj-item` 一行高约 36px，hover 和 `.on` 有底色。颜色只用 `theme.css` 里已有的变量。
- 行为（`nav.js` 页面层）：
  - 项目列表：`JSON.parse(params.get("projects") || "[]")`，解析失败当 `[]`；当前项目是已有的 `project` 变量。
  - 点 `projBtn`：浮层开/关切换；打开时清空搜索框、画列表、光标放进搜索框。
  - 搜索框 `input` 事件：用 `NavCore.projectItems(list, project, q)` 重画。
  - 点某项：当前项目 → 只关浮层；其他 → 关浮层并 `tell("superagent://project?path=" + encodeURIComponent(path))`。
  - 点“添加项目”：关浮层并 `tell("superagent://project-add")`。
  - 按 `Escape` 或点浮层和按钮以外的地方：关浮层。
  - 列表里的项目名用 `textContent` 写，不拼 HTML。

### P3 窗口外壳（main.swift）

- 加常量 `let recentLimit = 20`（放在 `recentProjectsKey` 旁边）。`remember` 里 `prefix(10)` 改成 `prefix(recentLimit)`。
- 加 `func recentProjectList() -> [String]`：读 `recentProjectsKey`，过滤 `isFolder`。`rebuildRecentMenu` 改用它（顶部菜单和左下角同一份）。
- 加 `func canSwitchTo(_ path: String) -> Bool`：`recentProjectList()` 里有这个路径且 `isFolder(path)`。
- `loadPanel` 里 nav.html 的地址末尾加 `&projects=` + `urlEncode(JSON 字符串)`，JSON 是 `recentProjectList()` 的字符串数组。**`&card=` 那一行（右栏地址）不要动**，老测试要求它带 `token=`。
- `webView(_:decidePolicyFor:...)` 的 `switch` 里加三个分支：
  - `case "project"`：取 `path`；等于 `project.path` 就什么都不做；`canSwitchTo(path)` 为真才 `switchTo(URL(fileURLWithPath: path))`，否则忽略。
  - `case "project-add"`：`if let url = askForProject() { switchTo(url) }`（复用现有选文件夹，不另做）。
  - `case "place"`：聊天页报当前对话和草稿。取 `thread`、`draft`（草稿 `prefix(2000)`），连同当前 `selectedCard` 存进 `UserDefaults`，键 `placeKey(for: project)`，值是字典 `["thread": ..., "card": selectedCard ?? "", "draft": ...]`。
- 加 `func placeKey(for url: URL) -> String { "place:" + url.path }`，以及读记录的小函数（返回 thread / card / draft，没有就空）。
- `selectCard(_:)` 里 `selectedCard = id` 之后，把当前项目记录里的 `card` 更新成 `id ?? ""`（其他两项不变）。
- `switchTo(_:)`：开头先 `chatWeb.evaluateJavaScript("window.SuperAgentChat && window.SuperAgentChat.place && JSON.stringify(window.SuperAgentChat.place())")`，在回调里把结果（`{thread, draft}`）连同 `selectedCard` 存进**旧项目**的记录，然后再做原来 `switchTo` 的全部动作。回调最多等 1 秒（超时照样往下切，用一个只执行一次的标记防止重复切）。原来的动作挪进回调时可以拆成一个新函数，**但新函数必须写在 `switchTo` 和 `remember` 之间**（老测试按这两个函数之间的文字检查：要有 `/api/clerk/preview`、`project = url` 在 `applyClerkSetting` 前、`applyClerkSetting` 在 `showLeft(firstLeft()` 前）。
- 原来 `switchTo` 里的 `selectedCard = nil` 保留；在 `applyClerkSetting` 回调里、`showLeft`/`loadPanel` 之后，如果新项目记录里有 `card`，设 `pendingPlaceCard = card`。
- 加 `var pendingPlaceCard: String?`。聊天页加载完成时（`WKNavigationDelegate` 的 `didFinish`，判断是 `chatWeb`），如果 `pendingPlaceCard` 有值：取出来、清空、调 `selectCard(card)`。卡已经不存在时，左栏现有逻辑会自己退回主对话，不用另外处理。
- 应用启动时（`applicationDidFinishLaunching`）没带 `--card` 的话，同样按记录设 `pendingPlaceCard`。带 `--project`、`--card` 的自测参数行为不变。
- `loadChat` 拼 chat.html 地址时，加 `&thread=` 和 `&draft=`（`urlEncode`，取当前项目记录；没记录就空）。

### P4 聊天页（chat.js）

- `window.SuperAgentChat` 加 `place: function () { return { thread: viewingCard ? (mainThread || "") : (currentThread || ""), draft: viewingCard ? "" : $("input").value }; }`。（看卡时输入框里的字属于卡的对话，不记。）
- 输入框 `input` 事件里，只在行政模式（`clerkMode && !butlerMode`）且没在看卡时，停 800 毫秒后 `location.href = "superagent://place?thread=" + encodeURIComponent(...) + "&draft=" + encodeURIComponent(...)`；切换对话（`clerkOpen`）后也报一次。草稿超过 2000 字只报前 2000 字。
- 页面打开时（行政分支里取完 `/api/clerk/list` 那段）：把 `clerkOpen(latest)` 改成 `var r = ChatCore.restorePlace(d.threads || [], { thread: params.get("thread") || "", draft: params.get("draft") || "" }); clerkOpen(r.open);` 然后 `if (r.draft) $("input").value = r.draft;`（调整输入框高度如有现成函数就调用）。`viewingCard` 为真那一支不变。

## 四、不做什么
