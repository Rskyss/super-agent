## T1 施工细节实测（11-22，真 agy 1.5.14）

| 问题 | 结论 | 证据 |
|---|---|---|
| 包装壳 `~/.local/bin/agy`（每次加“跳过权限”）能不能和 `acp` 一起用 | 能。`agy acp --dangerously-skip-permissions` 经包装壳（参数重复一次）正常握手，全程没来问权限 | 握手返回 Antigravity ACP Server 1.5.14；小活全程无 request_permission |
| 模型和强度怎么设 | `session/set_model`，modelId 就用配置里的编号（如 `gemini-3.8-flash-low`），和团队页列表一一对得上；不认识的编号报 `Unknown model ID: xxx` | set_model 返回 `{}`；错编号返回 -32602 |
| ACP 报的输入用量含不含缓存 | 不含。inputTokens 19369 + cachedReadTokens 30592 + outputTokens 1036 = totalTokens 50997 | 一次真跑的 prompt 返回值 |
| 跑命令的样子 | tool_call 的 name=`run_command`、args.CommandLine 是命令原文——直接对上看门人读的字段 | 真跑里 `ls`、`echo 42 > a.txt …` |
| 停工时 agy 会不会跟着停 | 会。翻译和它拉起的 agy 在同一进程组，`_stop` 整组停（假 agy 测试验证；真 agy 在 T5 后进程表里无残留） | test_agy_acp.Stop；T5 后 `ps` 无 agy acp 残留 |
