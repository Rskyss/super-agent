# 需求共识：行政人员放最上面，方便切换服务商和模型

状态：2026-11-06 ✅ 用户确认全部 6 条。

## 用户原话

“行政人员应该是在最顶上吧，因为是最核心的。然后应该可以方便地切换模型，现在我是腾讯云的 DeepSeek，后面假设换成百炼呢？”

## 要做什么

1. 设置页里，行政人员放在团队表格第一行，样子和下面四行一样，去掉“可选”两个字。
2. 这一行可以选服务商、选模型（也能手填）、看状态、点“检测”。
3. 服务商下拉里放腾讯云、阿里百炼、其他。“其他”可手填地址，接同类格式的服务，不保证都能用。
4. **每个项目各设一份。** 用户选择，没有采用“所有项目共用”的建议。
5. 每家服务商的密钥各存一把，只存在这台电脑的钥匙串里，切回用过的服务商不用重填。
6. 新项目没设过时，默认沿用最近一次用过的服务商和模型。**第一次在这个项目说话时固定下来**，之后别的项目换服务商，它不跟着变（2026-11-07 独立复查后明确，否则违反“换了 A 项目，B 项目不变”）。

## 怎么算做完

- 在同一个项目里从腾讯云换到百炼，再换回腾讯云，全程不用重填腾讯云密钥。
- 用真实腾讯云和真实百炼各走一遍：聊天、边生成边显示、查进度、弹“变成任务？”。
- 换了 A 项目的服务商，B 项目不变。
- 项目文件里找不到任何密钥。

## 不做

- 不在页面上自动拉取各家的全部模型列表。
- 不统计各家费用，不做按对话切换模型。
- 不改调度员、写测试、写代码、复查这四个角色的配置方式。
