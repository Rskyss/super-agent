方向不变：**质量不降的前提下优化流程**。看“一次到位率”：退回几次、问题多严重、改坏老功能没有、总用时。

## 一、修完后你能感受到的变化

1. **写代码那步看得出做到多少**（53）：右栏“写代码”标题行和说明之间多一条进度条，后面写“通过 120/269”。写测试那步显示“已写 N 项”，复查只显示用时。
2. **干活的人用中文汇报**（54）：右栏的进度话、交活汇报都是中文大白话（千问 DeepSeek 那次是英文）。
3. **检测查得出“接不上”**（55）：积木库和团队设置里的“检测”，从“建一个文件”改成一件小活：读一个文件、改一处、跑一条命令；同时看第一次交给模型的资料有多大，大得离谱（像 DeepSeek 那次 20 万）就提醒。Codex、Cursor、agy 升级后，提醒你重新检测一次。
4. **卡停下时，“继续改”的话已经替你写好**（56 甲）：复查退回用完停下时，调度员先让 Codex（最高强度、只读）把几轮复查合起来看，找出问题集中在哪、共同的原因，写出统一规则和要补的测试，预先填进“继续改”框，开头两句大白话说为什么每轮都有新问题。你看一眼，点发送；觉得不对可以改了再发。多等约 3–5 分钟。
5. **复查会收口**（57 丙）：退回过以后的复查，挑出的每条问题标上“这次改的”还是“原来就有的”。
   - 这次改动那一块里的严重、中等：照样退回去修（你说的“是真问题就值得现在修”）。
   - 改动范围以外的、轻微的：记进“以后再修”清单，放进项目时列给你看，不再拿来退回。
   - 连续两轮在同一块冒新问题：不再一条条退回，直接走第 4 条，先找共同原因。
6. **台账的返工次数对得上**（58）：自动记的“返工 N 次”把复查退回也算上（69b 写成“返工 0 次”，其实退回了 4 次）。
7. **改坏老功能，流程自己就能查出来**（59）：
   - “相关老测试”改了页面文件也会挑，并顺着测试用的辅助脚本找（69b 只改了页面文件，现在的做法只看 .py，一项都没挑）。
   - 复查的同时，程序在一份副本上跑全量测试（真 AI 工具藏起来），全量不过就当测试没过退回。Claude 最后跑全量这一步搬进流程，不另外多等 13 分钟。
8. **Claude 写施工单更准**（56 乙，这条是 Claude 自己的规矩，不改程序）：施工单凡是“重开后接着显示”“隔一会儿去问进度”，必须写清四件事：什么算真的没了、连不上怎么显示、隔多久再问、不能同时问两次。拆文件时，把引用旧文件的老测试都列进测试命令。写进施工单 README 的检查清单。

## 三、拍板的题（用户 11-13 四题都选推荐）

定下的：进度条最多每 2 分钟算一次、在副本上跑；检测加强这轮做；复查退回用完停下就起草“继续改”；全量不过自动退回写代码的、退回次数照算；Claude 直接改、Codex 独立复查。

1. **进度条的数多久算一次？**（53）
   你定的是“写代码的每改一次文件，程序在后台跑一遍本卡新写的测试”。泼冷水：千问一轮改几十次文件，69b 本卡测试一次约 1–3 分钟；每改一次都跑，电脑会一直很忙，还可能和写代码的自己跑测试撞车（抢同一个临时文件夹、端口）。
   - **推荐：最多每 2 分钟算一次**，在一份副本上跑，只跑写测试交出的那几个文件；数会晚一两分钟。
   - 或：照原话，每改一次就跑。
2. **检测加强（55）这轮做不做？**
   - **推荐：做**。今天千问 4 被拒、DeepSeek 反复压缩，都是开跑以后才发现，白跑了 21 分钟、查了 42 分钟；检测查得出来就能在开跑前拦住。
   - 或：先放着，这轮只做 53、54、56–59。
3. **自动起草“继续改”（56 甲）在什么时候起草？**
   - **推荐：只要是复查退回用完停下就起草**（测试的问题、范围问题这类停下，照现在的大白话提示，不起草）。
   - 或：只在“每轮冒新问题”停下时起草。
4. **全量测试搬进流程（59）：全量不过怎么办？**
   - **推荐：当测试没过，自动退回写代码的**，交代里写明“哪几项老测试坏了”；退回次数照算。
   - 或：不退回，停下来给你看（等于现在 Claude 查出后的做法）。

另外照前三轮：**Claude 直接改、Codex 独立复查**（改的是派活程序本身，不交超级助手自己跑）。有异议就说。

## 四、怎么算做完

- 每条先写测试、看它不过，再改到过；全量通过（真工具藏起来跑）。
- Codex 独立复查通过。
- 真实窗口：开一张小卡用千问跑一遍，看进度条在动、汇报是中文、复查收口；故意让复查退回用完，看“继续改”框是否已填好；积木库里检测一个已知接不上的组合，看能不能拦住。
- 台账、试跑记录（各条改“已修”）、调度手册、施工单 README 同步。
