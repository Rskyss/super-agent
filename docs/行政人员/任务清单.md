# 任务清单：行政人员（第一期）

状态：🔄 用户 2026-11-06 批准，施工中。

依赖关系：卡 1 → 卡 2、卡 3 → 卡 4 → 卡 5、卡 6 → 卡 7 → 卡 8 → 卡 9。

- [x] **卡 1 模型连接和假模型**
  - 做什么：能和腾讯云模型对话，回复逐字返回；做一个不花额度的假模型用于测试。
  - 怎么验收：断网、密钥错误、额度用完、回复中断都有大白话提示；全部用假模型测过，再用真实模型试一次。
  - 依赖：无。
- [x] **卡 2 第一屏和密钥**
  - 做什么：第一次打开时选服务商、填密钥、测试并保存到钥匙串。
  - 怎么验收：填错不能保存；填对进入聊天；重开不再询问；项目文件和日志里搜不到密钥。
  - 依赖：卡 1。
- [ ] **卡 3 行政聊天窗口**
  - 做什么：聊天改成找行政；对话保存在本机；可新开很多段；切换不用等；行政自动起名。
  - 怎么验收：闲聊不启动 Codex；切换马上显示；重开内容还在；没说话的空对话不保存。
  - 依赖：卡 1。
  - **做完给你看一次。**
- [ ] **卡 4 读项目和回答进度**
  - 做什么：行政能读项目说明、台账、卡片和设置，并解释报错。
  - 怎么验收：回答进度和卡片记录一致；没有改文件和运行命令的能力，测试尝试越权会被拒绝。
  - 依赖：卡 3。
- [ ] **卡 5 左栏和旧 Codex 对话**
  - 做什么：左栏显示行政对话，旧 Codex 对话单独一组，默认收起，只能看。
  - 怎么验收：旧对话能打开查看，不能发消息，不启动可写连接；想继续时提示用终端。
  - 依赖：卡 4。
- [ ] **卡 6 变成任务确认框**
  - 做什么：行政判断是任务时弹确认框，写清要做什么、不做什么、怎么算做完。
  - 怎么验收：闲聊和查询不弹；取消不生成卡片；确认后生成卡片。
  - 依赖：卡 4。
- [ ] **卡 7 写方案、批准和开工**
  - 做什么：Codex 只读写方案和允许范围；你批准后在后台开工；行政汇报完成或卡住。
  - 怎么验收：写方案时不改代码；没批准不开工；已有运行中的卡时不开第二张；关掉聊天不影响后台任务；失败时能看到原因。
  - 依赖：卡 5、卡 6。
  - **做完给你看一次。**
- [ ] **卡 8 改设置和带你配团队**
  - 做什么：行政能提议改团队设置，第一次带你配好。
  - 怎么验收：不确认不改；确认后和设置页看到的一致；检测失败时告诉你怎么办。
  - 依赖：卡 7。
- [ ] **卡 9 收尾**
  - 做什么：用一批真实对话测判断准确度；确认模型价格；打包安装；真实窗口走完全程；更新文档和台账。
  - 怎么验收：需求共识 10 条全部通过；独立复查通过；全量测试在 Python 3.9 / 3.15 都通过。
  - 依赖：卡 8。

每张卡都按规矩来：先写失败的测试，做完验证，再做独立复查，通过后本地存档，不推送。
