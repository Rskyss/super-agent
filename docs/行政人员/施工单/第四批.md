## 42 方案写明怎么看

**验收测试：** `tests/test_acceptance_42_plan_view.py`

**改动文件：** `collab/planner.py`、`desktop/view.py`

**约定：**

- 方案要求多三项字符串：`view_how`（大白话，怎么看结果）、`view_command`（启动命令，可为空）、`view_url`（打开的地址，可为空）。都放进给 Codex 的 schema 的 `required`。提示词写明：网页类项目填本机启动命令和 `http://127.0.0.1` 地址，端口不要和项目日常开的相同；不是网页就留空，只写 `view_how`。
- `_validate_answer` 不因这三项失败，老答案没有它们也通过。
- 清理规则写成一个函数：命令解析不了、地址不是 `127.0.0.1` 或 `localhost`，命令和地址都清空，`view_how` 保留。
- `开工.json` 只写非空的项。
- 方案文件增加 `## 做完后怎么看结果`，写 `view_how` 和命令（用户批准时能看到）。注意 `has_blanks` 不能被空内容触发，三项都空时写“方案里没写”之类。
- `card_view` 在阶段是 `review` 或 `merge_failed` 时多一个 `accept`：`{"result": 方案的验收标准, "how": view_how, "can_preview": 命令和地址都有}`。其他阶段没有这个键。

## 43 打开改好的版本

**验收测试：** `tests/test_acceptance_43_preview.py`

**改动文件：** 新建 `desktop/preview.py`、`desktop/server.py`、`desktop/static/panel.html`、`desktop/static/panel.js`、`desktop/static/panel.css`、`desktop/mac/Sources/SuperAgent/main.swift`

**`PreviewHub(wait_seconds=60)`：**

- `start(project, card_id)`：先结束上一个。副本不在：`{"ok": False, "reason": 含“不在了”}`。
- 从 `开工.json` 读命令和地址，只运行这里面的。没有命令，或地址不是本机：`{"ok": True, "mode": "folder", "path": 副本}`。
- 地址已经能访问：不启动，`{"ok": False, "mode": "folder", "path": 副本, "reason": 含“占用”}`。否则用户会把别的程序当成改好的版本。
- 启动前把项目里的 `node_modules` 链接到副本的相同位置：只找 3 层以内，不进 `node_modules` 和 `.git`；副本里没有上一级文件夹就跳过；已存在就不动。
- `shlex.split` 后运行，不用 `shell=True`，工作目录是副本，`start_new_session=True`，输出写到卡片文件夹的 `预览输出.log`。
- 等地址能访问（HTTP 错误也算起来了），成功：`{"ok": True, "mode": "web", "url": 地址}`。进程提前退出或超时：结束它，`{"ok": False, "mode": "folder", "path": 副本, "reason": 大白话}`。
- `stop()` 结束整组进程：先 TERM，等几秒再 KILL。`status(project, card_id)` 返回 `{"running": bool, "url": 地址或空}`，换了卡算没在运行。

**本机服务：**

- `server.preview = PreviewHub()`。`POST /api/clerk/preview`，body 有 `project`、`card`、`action`（`start` 或 `stop`）；卡片编号不合规回 400。`GET /api/clerk/preview?project=&card=` 返回 status。都要口令。
- `_do_card_action` 开头先 `preview.stop()`。退出时也要结束：正常退出和 `_exit_with_parent` 都要覆盖，不能留下进程。

**右栏：**

- `actions` 区上方加 `id="acceptBox"`，只有 `view.accept` 存在时显示：标题“做完了，请你确认”；“你应该看到”`id="acceptResult"`；“在哪看”`id="acceptHow"`；按钮 `id="previewBtn"`。
- 按钮文字：有 `can_preview` 时“打开改好的版本”，运行中“关闭预览”；没有时“打开文件夹”。启动等待期间显示“正在打开…”并禁用，等待可能要几十秒。
- 成功：`location.href = "superagent://clerk-open?project=…&url=…"`。文件夹模式用 `&path=…`。失败：显示原因，有 `path` 时给“打开文件夹”。
- 切卡片时用 GET 取状态，刷新按钮文字。
- 用户内容都用 `textContent` 或转义，方案内容不能当网页执行。

**窗口：** `case "clerk-open"`：

- `url` 只放行 `http` 且域名是 `127.0.0.1` 或 `localhost`。
- `path` 只放行 `<当前项目上一层>/<项目名>-worktrees/` 里面的文件夹。
- 都用 `NSWorkspace.shared.open`。
- `switchTo` 里发 `POST /api/clerk/preview` 的 `stop`（body 带旧项目）。
