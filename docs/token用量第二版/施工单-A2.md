## 三、具体做法

### 1. 取数统一入口（`collab/token_usage.py`，只加不改已有函数的行为）

`usage_for(tool, output="", live=None)`：
- `codex`、`qwen`：先 `usage_from_text(output)`，不 ok 且给了 `live` 再 `usage_from_log(live)`（和现在 `dispatch._tokens_for` 的做法一样，挪到这里）。
- `agy`：数据来自 `output` 文本，没有就读 `live` 文件。按行解析 JSON（坏行、半截行跳过）：有 `event == "result"` 且 `result.usage` 是对象，就用它；没有就把所有 `event == "step_update"` 里 `step_update.usage` 相加。都没有 → 读不到。
- `cursor`：同样按行解析，取最后一条 `type == "result"` 的 `usage`。没有 → `{"ok": False, "pending": True, "reason": "这一轮结束后出数"}`。
- 换算成统一口径（合计 = 输入 + 输出，输入含缓存读取；思考已含在输出里，不另加）：
  - agy：`input = input_tokens + cache_read_tokens`，`cached = cache_read_tokens`，`output = output_tokens`，`reasoning = thinking_tokens`
  - Cursor：`input = inputTokens + cacheReadTokens + cacheWriteTokens`，`cached = cacheReadTokens`，`output = outputTokens`，`reasoning = reasoningTokens`
  - `total = input + output`，`children = 0`
- 其他工具（含空字符串）→ 返回 `None`。
- 任何异常、文件不存在、格式认不出 → `{"ok": False, "reason": "<大白话原因>"}`，**绝不往外抛**。
- 读实时输出文件按（路径、大小、修改时间）缓存结果，同一个没变的文件不反复读。大文件可以先读尾部找 `result`，找不到再整份读。

### 2. 记录（`collab/dispatch.py`）

- `_tokens_for`：去掉“只有 Codex 壳”的判断，改成调 `usage_for(adapter, output, live)`。
- 备交接资料那段：同样改调 `usage_for`，`None` 时不写 `tokens` 字段。
- 其他行为不变。

### 3. 右栏取数（`desktop/view.py`）

- `_add_tokens`：去掉三处 `tool in ("codex", "qwen")` 的限制。
  - “回复”没有 `tokens` 字段时：按 `reply_to` 找对应“派活”，有 `live` 文件就 `usage_for(tool, live=...)` 现算（老卡补数）；都没有 → 记一条读不到（原因写清）。
  - 在跑的“派活”（还没回复的）：一律 `usage_for(tool, live=...)`。
  - `pending` 的（Cursor 在跑）：站位 `tokens` 显示它，**不算**没读到、不进合计。
- 每轮明细 `history[i]`：在现有 `seconds`、`tokens` 之外加 `who`（`"<工具显示名> · <派活事件里的 model>"`，没有 model 就只写工具名；工具显示名用文件里现成的 `TOOL_NAMES`），读不到的轮加 `missing: True` 和 `reason`。
- 站位 `tokens` 的 `missing` = 没读到的轮数；`card_view` 返回的 `tokens` 加 `missing`（全卡没读到的轮数）。
- 已有字段一律不改。

### 4. 右栏显示（`desktop/static/panel.js`）

- `metaText`：`tokens.pending` 时显示 `tokens.reason`（“这一轮结束后出数”），不写“用量 —”。
- `stepTitle`：每轮一行 `第 N 轮 <who> · <用时> · <用量>`；没有 `who` 的老记录照旧 `第 N 轮 <用时> · <用量>`；`missing` 的轮用量写 `用量 —（原因）`。
- `totalText`：`missing > 0` 时末尾加 `（不含没读到的 N 轮）`。
