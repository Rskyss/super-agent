# 方案：打开文件夹即用

> 状态：✅ 已批准（2026-11-04 用户选 A）并施工完成，⏳ 待用户验收，见 [验收记录](验收记录.md)　依据：[需求共识](需求共识.md)  
> 读法：第 1–6 节是产品语言；第 7 节给施工用，可跳过

## 1. 打开一个文件夹会发生什么

**第一次打开（项目里还没有协作记录）**
1. 超级助手自动“接入”：在项目里建 `.collab/`，并把它加进项目的“不提交”名单。**不复制协作包。**
2. 左边启动你给这个项目选的调度员（第一次要你亲手选），并自动交代一句开场话：
   > 这是第一次接入。先读调度手册，再熟悉这个项目（结构、怎么运行、怎么测试、哪些不能动），起草一份项目说明给我确认。不要改任何代码。
3. 你确认项目说明后，它存进项目的 `docs/项目说明.md`。

**以后每次打开**
- 调度员自动收到开场话：
  > 先读调度手册、项目说明、台账最近的记录和任务板，用两三句话告诉我项目进行到哪、有什么待办。不要改任何文件，等我说需求。
- 开场话会显示在左边，你看得到它被交代了什么。

**代码体检**：只在你说的时候做。

**不是 git 项目**：照常能聊天，但右边会提示“这个项目还没有版本管理，不能派活”，不假装能做。

## 2. 已经用旧方式装过协作包的项目（例如视频项目）

第一次用新方式打开时，弹出一个询问：
> 这个项目里有一份旧的协作包（`collab/` 文件夹），以后改用超级助手自带的。要删掉项目里的旧协作包吗？

- 你点同意才删；不同意就留着，不影响使用。
- 协作记录（`.collab/`）一条不动；旧的“项目档案”复制成 `docs/项目说明.md`；把 `.collab/` 加进不提交名单。
- 说明：视频项目里这份旧协作包没进 git，删了就没了，但它只是一份副本，随时能从超级助手里重新拿到。

## 3. 记录分层（已确认）

| 放哪 | 放什么 | 进不进 git |
|---|---|---|
| 项目 `docs/` | 台账、项目说明、做完的需求/方案/验收、过程摘要（执行记录、测试结果、返工记录、复查结果、汇报） | 进 |
| 项目 `.collab/` | 卡片、交接全文、实时输出、页面检查工具 | 不进（已加进不提交名单） |
| 超级助手自己 | 打开过的项目列表、每个项目选的调度员 | — |

**一处调整**：卡片归档时，交接全文和实时输出**不再**复制进 `docs/`，只留在本机 `.collab/`（这是上一步刚加的行为，按新口径收回）。

## 4. 超级助手自己记什么、在哪改

- 菜单「文件 → 最近打开」：列出打开过的项目，点一下就切过去。
- 每个项目选的调度员分别记住：视频项目用 Codex、另一个项目用 Claude，互不影响。
- 协作包以源目录（`~/Desktop/project/super-agent`）为准：超级助手优先用源目录里的那份，源目录不在时才用应用里自带的。这样改了协作包不用重新生成应用。

## 5. 不开客户端时（只用终端）

在任何项目里对 Claude 说“用协作包做……”：不再往项目里复制协作包，直接用源目录那一份；项目没接入过就先接入（同第 1 节）。全局技能和调度手册同步改写。

## 6. 这一步不做 / 风险

- 不做：一次开多个项目窗口（先一个窗口、用菜单切换）；换电脑同步超级助手的项目列表。
- 风险 1：“接着上一次对话 + 自动交代开场话”这个组合，Codex 要实测确认；Claude 由你亲手配置时一起确认（按你的要求，我测试时不启动 Claude）。
- 风险 2：调度员是 AI，开场话只能交代，不能保证它百分之百照做；照不照做，你在左边看得见。

## 7. 施工备注（可跳过）

- `collab init` 负责接入：建 `.collab/`；项目 `.gitignore` 追加 `.collab/`（没有就新建，已有不重复）；不复制包。
- 项目说明：新位置 `docs/项目说明.md`；读取时新位置优先，旧位置 `.collab/项目档案.md` 兜底；`confirm-profile`、`approve` 同步。
- `collab install`：不再复制包，改为提示“不需要安装”并执行接入；`--update` 同理。
- 新增 `collab migrate <项目> [--remove-old-package]`：识别旧协作包（以 `规则.md` 为标记，非协作包的同名文件夹绝不碰），搬项目说明、加忽略；只有带上删除参数才删旧包。
- `.collab/README.md` 骨架里的规则书、手册路径改成协作包的实际位置（绝对路径）。
- 归档不再复制 `流转/` 和 `流转.jsonl`。
- 客户端：打开时调用接入；发现旧包弹窗询问；调度员选择按项目路径分别保存；最近打开的项目菜单；开场话分“第一次 / 每次”两种；协作包与面板优先用源目录。
