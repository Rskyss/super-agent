# 项目说明

- 这个项目是做什么的：超级助手是一个让多家 AI 分工完成软件开发的协作工具，提供任务拆解、施工、测试、复查和验收，并通过 Mac 窗口里的积木库接入工具和大模型。
- 怎么启动：日常打开已安装的“超级助手”应用并选择项目；网页服务可在项目根目录执行 python3 desktop/server.py --port 18768 --token preview-68b，服务本身固定绑定 127.0.0.1。
- 怎么测试（测试命令）：在项目根目录执行 python3 -m unittest discover -s tests，运行前用 pgrep -fl unittest 确认没有其他测试在跑，并确保已安装 Node.js，以执行测试调用的 JavaScript 检查。
- 禁区（哪些不能动）：用户真实的积木库资料、钥匙串和密钥（API 密钥只放 .env，不提交）；已有测试只由写测试的人改，开发员不改；旧施工单、验收记录、台账等历史文档保持原样；改 desktop/mac/（Mac 窗口外壳）要重新安装，施工单没写就不要动；不推送。
- 技术栈：Python 3.9 及以上、Python 标准库 HTTP 服务和 unittest、原生 HTML/CSS/JavaScript、Node.js 页面规则检查、macOS Swift/AppKit 与 SwiftTerm、Git。
