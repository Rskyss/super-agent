### 严重问题

1. **首次登记发生在两遍之间，第二遍测出的新失败仍被放过。** 复现可在副本根目录用下面的命令。验收里的 `Round3Python` 自带一个原本就失败的等卡测试和一个原本通过的老测试。第一遍跑完才登记，再把老测试改坏，`finish(1)` 仍返回“过”。同一原因也影响人工接受：首次登记发生在开跑后，等状态锁时改坏代码，仍能进“待验收”。**改法**是记住开跑时有没有名单。运行中首次出现名单，就让整组结果作废重跑。一直无名单的项目可以继续走老流程，不用多扫一遍目录。[自动关卡](/Users/rs/Desktop/project/开发助手-worktrees/CARD-033/collab/dispatch.py:3239) · [人工接受](/Users/rs/Desktop/project/开发助手-worktrees/CARD-033/collab/accept.py:126)

   ```bash
   PYTHONPATH=tests python3 -B -c '
   from test_card_gap_b2s_acceptance import Round3Python, _py_test
   from collab.dispatch import _FullSlot
   from collab.fullrun import FullRunner
   t = Round3Python()
   t.setUp()
   try:
       s = _FullSlot(FullRunner(), t.wt, t.cdir)
       s.start()
       s.thread.join()

       t.tearDown()'
   ```
