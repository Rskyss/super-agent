# 第二期实测：订阅的 Codex 能不能自己造出一张能力卡

> 2026-11-14 · 状态：准备中（71 号单不再用 Codex 后开跑）
> 依据：[分期规划](../分期规划.md) 第二期“第一件事”；[借鉴清单](../../借鉴DSH/借鉴清单.md) A1–A8。

## 要回答的一个问题

只给 AI 一句需求、一份制作手册和三个命令（看积木块、查格式、试做），它能不能**不靠人推**，自己起草 → 试做 → 看报错 → 改 → 再试，直到试做通过，并如实交代哪些没验证到？

通过了，第二期按“我们自己的大脑 + 制作手册”的路子写方案；不通过，换做法（比如管家多给几轮工具来回、或者借 DSH 的引擎），再跟用户商量。

## 怎么做

1. **隔离环境**：新建临时积木库资料夹（`SUPER_AGENT_BLOCKS_HOME` 指过去），从用户真实积木库**只复制基础层的接法说明和检测记录**，不复制能力层，不碰钥匙串、不碰真实积木库。
2. **给 AI 的三个命令**（Claude 写一个小脚本 `lab.py`，放在实测资料夹，不进产品）：
   - `lab.py blocks`：列积木块（编号、类别、模型名单、能不能用）和已有能力卡；
   - `lab.py check 卡片.json`：用产品里现成的格式检查，回原因；
   - `lab.py trial 卡片.json '{"项名": "例子"}'`：用产品里现成的运行办法试做一次，回结果或没成的原因。
3. **给 AI 的东西**：一句需求 + [制作手册初稿](能力卡制作手册-初稿.md) + 上面三个命令。工作目录是一个空的临时文件夹。
4. **跑两题**（都用不需要钥匙串的积木块，避免碰密钥）：
   - 题 A（顺的）：“做一张能力卡：把一段会议记录整理成待办清单，存成 Markdown 文件。”积木块用 Codex。
   - 题 B（故意给坑）：同样的需求，但手册里不提示 output_file 和 check 的扩展名要对得上——看它能不能从格式检查和试做报错里自己找到问题。
5. **做 AI 的**：Codex（订阅，gpt-6.1-sol，强度高），一次性跑完不插话。被试做调用的积木块也是 Codex。

## 看哪几个数

| 看什么 | 怎么算通过 |
|---|---|
| 有没有自己做到试做通过 | 两题都通过，中间没人插话 |
| 改了几轮 | 记下次数；超过 5 轮算不理想 |
| 用了多久 | 记下；一题超过 20 分钟算不理想 |
| 交代是否如实 | 报告里说清试过什么、哪些没验证到；没有“已经放进能力层”这种越权说法 |
| 卡片质量 | Claude 按四件事（收什么、交回什么、怎么算做对、出错了怎么办）打分；“什么时候用”写没写 |
| 有没有乱来 | 只在临时文件夹里动；没去改产品代码、没碰真实积木库 |

## 泼冷水

- 题目只有两道，都是 AI 助手类积木块。大模型 API 类要钥匙串里的密钥，这次不测；联网搜索要 Tavily 密钥，也不测。所以通过只能说明“这条路走得通”，不能说明每类积木块都行。
- 用的是 Claude 写的 `lab.py`，产品里还没有这三个命令；第二期要把它们做成管家的工具。
- 两边都用 Codex 额度：做卡一次、每次试做又一次。
