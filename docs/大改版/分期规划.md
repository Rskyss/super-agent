# 大改版分期规划

> 2026-11-14 · 状态：**用户批准**（11-14 “那现在先开发第一期吧”）
> 依据：[借鉴清单](../借鉴DSH/借鉴清单.md)、[精读报告核实记录](../代码精读报告/核实记录.md)、[卡片规则讨论记录](../积木库/能力层/讨论记录-卡片规则.md)、台账最上面的“大改版总排期”。
> 本文把原来的 0–6 步整理成四期。原则（用户 11-14）：**以后要重做的老东西现在不修，挪到重做它的那一期，写成新做法必须做到的要求。**

## 总览

| 期 | 主题 | 做完你能用上什么 | 规模 |
|---|---|---|---|
| 一 | 打地基 | 安全问题清掉，能力层第一版走查一遍、推到 GitHub | 小，剩半天左右 |
| 二 | 能力层：说话造能力 | 跟 AI 说“帮我做个能 xx 的能力”，它自己起草、试做、修到通过，再交给你确认 | 大 |
| 三 | 业务流程层：说话搭流程 | 跟 AI 讨论清楚一件业务，它把能力卡搭成流程，你批准、试跑、保存，以后反复用；现在这套开发团队变成第一条现成流程 | 最大 |
| 四 | 扩展 | 积木库能接外部服务（MCP）；验收过的流程能定时自动跑 | 中 |

一期做完给你看、你确认了才开下一期。二、三、四期各自都是大需求：开工前先写需求共识、方案、任务清单，每份你批准了才动手。第四期的“接外部服务”不依赖第三期，需要时可以提前插到第二期之后。

## 第二期：能力层，说话就能造出能力

**目标：** 你跟 AI 说一句“帮我做一个能 xx 的能力”，它照制作手册自己起草、试做、看报错、修改，直到试做通过，再交给你点“放进能力层”。你不用再一轮一轮推它。

**第一件事（开工前）：** 1 天实测。在临时文件夹里让订阅的 Codex 照一份制作手册的初稿，自己做出一张试做通过的卡。通过才写需求共识；不通过就换做法，再跟你商量。

|---|---|---|

| 2-2 | 自己写、试、修：试做失败自动接着改，有次数上限；到上限就停下，说清卡在哪 | 借鉴 A2 |

## 第三期：业务流程层，说话就能搭出流程

**目标：** 你跟 AI 把一件业务讨论清楚，它挑能力卡搭成流程草稿；你批准后试跑；通过就保存，以后反复用。现在这套开发团队（行政、调度员、写测试、写代码、复查）变成**第一条现成的业务流程**。

| 编号 | 需求 | 出处 |
|---|---|---|
| **搭流程** | | |
| 3-1 | 先讨论清楚 → 出流程草稿 → 你批准 → 试跑；不批准就提意见让它接着改 | 借鉴 B1 |
| 3-2 | 流程卡：名字、用途、什么时候用、分几个阶段、用了哪几张能力卡、前后怎么衔接、最后交付什么 | 借鉴 B2 |
| 3-3 | 试跑一直跑到完成，或卡住时用一句人话说清卡在哪；有轮数上限 | 借鉴 B4 |
| 3-4 | 流程验收过才保存，保存的是固定组合，每次跑都一样（不是 AI 每次现写） | 借鉴 B3（不采纳的反面） |
| **开发团队变成第一条流程（项目窗口流程大改）** | | |
| 3-5 | 团队、行政、调度员按新的流程层重做；调度员负责串流程，行政是锁需求的对话入口 | 产品文档 11-09 对齐 |
| 3-6 | 新流程必须做到：“接着跑”失败时状态不乱改 | 精读 C17 |
| 3-7 | 新流程必须做到：停施工先核对身份，不误停别的程序 | 精读 S8 |
| 3-8 | 新流程必须做到：转达给卡片的话不丢 | 精读 C10 |
| 3-9 | 跑开发卡时攒下的体验问题（试跑记录里记的）一起改；**必修**：右栏任何时候都有一步在转圈，本卡测试、相关老测试、全部测试分开显示并计时，跑测试和复查也有进度（试跑记录 64、65、66） | 11-14 用户定的规矩；卡 71 用户截图 |
| 3-10 | 项目窗口那几条再看一遍：设置文件安全写法、迟到的保存写错项目、同一张卡存两次档、清记录撞车、坏卡让面板出错、自测会碰真实设置——代码还在就修，重做掉了就划掉 | 精读 C4、C5、C6、C9、C11 + 11-14 新增 |
| 3-11 | 小需求走短流程：写完直接跑相关测试就交给用户，大需求照旧走六步 | 借鉴 E1；按需求大小调配讨论记录 |
| 3-12 | 退回返工时接着上一轮对话改，不重新理解整张卡 | 借鉴 E4；试跑记录 69 |

**不做：** 定时跑（第四期）。
**怎么算做完：** 你说一件业务，拿到一条试跑通过、能反复用的流程；开发团队那条流程能照常跑一张开发卡。

## 泼冷水

- **第二期的 1 天实测是整个改版的第一道关。**“订阅的 Codex 自己写、试、修”只是判断，没验证过。
- **工作量：** 第二、三期现在估不准，各自走规划时再估。第三期最大，会动项目窗口。
- **挪走的 C17、S8、C10：** 第三期之前跑开发卡时这三个问题还在。都很少碰上，真碰上按“挡路的马上修”处理。
- **界面：** 不单独做一轮全面改版，每期改它用到的页面。
