# 超级助手设计规范

新页面和新功能都按这份来。颜色和尺寸的唯一来源是 `desktop/static/theme.css`，页面里不写死色值。

## 1. 原则

1. **内容优先**：界面退到后面，让对话和进度说话。能用状态表达的，不写句子。
2. **一处一个重点**：一屏只有一个橙色主操作。
3. **颜色只表达状态**：橙色是进行中和主操作，蓝色是等你，绿色是完成，红色是出错。不用颜色做装饰。
4. **像 Mac 应用**：左栏用系统半透明材质，窗口顶部不留灰色标题栏，三段从上到下贯通。
5. **安静但有回应**：悬停、按下、选中都有反馈，动效短，不抢注意力。

## 2. 颜色

| 用途 | 变量 | 值 |
|---|---|---|
| 中间背景 | `--bg` | `#17181b` |
| 右栏背景 | `--bg-side` | `#131417` |
| 浮起的卡片 | `--bg-raised` | `#1c1d21` |
| 控件底色 | `--surface` | `#212327` |
| 悬停、选中 | `--surface-2` | `#2b2d33` |
| 未完成 | `--surface-3` | `#3a3d44` |
| 细线 | `--hair` | 白色 7% |
| 控件描边 | `--hair-2` | 白色 12% |
| 主文字 | `--text` | `#ecedef` |
| 次要文字 | `--dim` | `#a0a4ad` |
| 弱文字 | `--faint` | `#858a94` |
| 进行中、主操作 | `--accent` | `#f0a23b` |
| 等你 | `--wait` | `#7fb2f0` |
| 完成 | `--ok` | `#62cc93` |
| 出错 | `--bad` | `#f0776c` |

每个状态色都有 `-soft` 版本，用作状态标签和高亮的底色。文字对比度不低于 4.5:1。

## 3. 文字

| 级别 | 字号 | 用途 |
|---|---|---|
| `--fs-2xl` | 22 | 页面标题 |
| `--fs-xl` | 18 | 卡片标题 |
| `--fs-md` | 14 | 正文 |
| `--fs-base` | 13 | 列表、控件 |
| `--fs-sm` | 12 | 辅助信息 |
| `--fs-xs` | 11 | 分组标题 |

- 字体用系统字体和苹方；编号、计时、用量用等宽数字。
- 字重只用 400、500、600。
- 对话正文行高 1.75，界面行高 1.5。

## 4. 间距、圆角、层次

- 间距按 4 的倍数：4、8、12、16、20、24、32。
- 圆角：小控件 6，控件 8，气泡和卡片 12，浮层 14。
- 层次靠底色和细线，只有输入框、确认卡、下拉菜单这类浮起的东西用阴影。

## 5. 动效

- 悬停和按下 120 毫秒，展开和切换 180 毫秒，统一缓动。
- 只有“正在进行”的东西会呼吸。
- 系统开启“减弱动态效果”时全部关闭。

## 6. 组件

- **状态标签**：圆点加文字，底色用 `-soft`。
- **流程步骤**：完成是对勾，进行中是转圈，等你是蓝点，未开始是小圆点。只有正在发生的那一步用浮起的底色，并完整显示文字。
- **左栏结构**（2026-11-06 改）：最上面是“主对话 | 等待处理”两个标签，点标签只换左栏列表，中间内容不变，点列表里的一项才切换。主对话标签：新对话和历史对话。等待处理标签：所有卡片，依次是等你处理、进行中、已完成；有卡等你处理时标签上显示数字。搜索只搜当前标签。中间页面只放对话内容。
- **右栏**：只属于任务卡片。主对话里不显示任何流程，点开一张卡才出现，而且只显示这张卡自己的记录。
- **列表行**：标题一行，下面一行状态；选中时底色变亮，不加边框。
- **按钮**：主按钮橙底；次按钮透明加描边；文字按钮只在悬停时有底色。
- **下拉框、输入框**：高 32，聚焦时描边变亮。
- **确认卡**：浮起的卡片，标题用状态色，操作放底部。

## 7. 文案

- 只写状态和结果，不写操作说明。
- 按钮写动作：“保存”“检测”。
- 出错时写两句：哪里错了、怎么办。
- 界面不出现内部词，比如“需Claude介入”显示成“需要你处理”。
