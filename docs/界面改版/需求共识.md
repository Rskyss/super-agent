# 需求共识：界面改版（方向 E，深色）

## 用户原话

- 卡片是这个助手最重要的东西，点开卡片看流程和交接，不该和卡片并列。
- 现在看起来像很垃圾的 demo，说明文字太多。
- 产品更像 Muse，多一层卡片，可以灵活切换。
- 右边的选项放到右栏，可以点开收起。
- “用 E 的方式先把整体 UI 调整一下，记得换深色的。”

## 已拍板

| 事项 | 口径 |
|---|---|
| 方向 | E：左边主对话和卡片列表，中间对话，右栏放流程和交接、可收起 |
| 配色 | 深色 |
| 先后 | 先改整体界面，新功能后面单独做 |
| 产品主流程（后续阶段做） | 先聊天；调度员判断值得做时问“变成任务？”；用户确认才生成卡片并派活；闲聊和查问题不成卡 |

设计稿：[超级助手界面改版](https://claude.ai/artifact/H1qGrSFcdQMWmAeX3pvqPM)，最下面一行。

## 这次做

1. 窗口分成三段：左栏、中间、右栏，右栏可以收起。
2. 左栏：搜索、主对话、卡片列表、项目名、设置。
3. 右栏：卡片标题、状态、计时、七段进度，下面切换流程和交接。
4. 聊天、终端、右栏、设置统一成一套深色。
5. 删掉操作提示和解释句，只留状态和数字。
6. 设置页改成每个角色一行，保留刚做好的单独检测和保存规则。

## 这次不做

- “变成任务？”确认框和“确认，开工”按钮。
- 每张卡自己的对话。
- 多张卡同时跑。
- 新增卡片状态或改变派活流程。

## 怎么算通过

1. 打开窗口看到三段，所有页面都是同一套深色。
2. 点左栏卡片，右栏显示这张卡的流程和交接；点主对话，右栏回到跟随最新进度。
3. 右栏能收起和展开，重开窗口后记得上次的状态和宽度。
4. 聊天和终端来回切换、历史对话、新对话、允许/拒绝都还能用。
5. 设置页的单独检测和保存规则不变。
6. 全部自动测试通过，并在真实窗口里走一遍。
