## 二、过程中发现的问题

1. **超级助手还不懂我们的规矩和项目**：问它“clear 之后编号会重排吗”，它答得又长又泛，还反问要不要去看代码——因为它没有我们的说明书，也没绑定到测试项目。第 1 步要把规矩写成 DSH 说明书、把项目设成它的工作区。
2. **这次走了一条捷径**：插件通过一个网页地址把请求转给现在的后台。DSH 桌面版不走网页，正式做要换成 DSH 自己的接口方式（要编译、生成接口），多 1–2 天。这条转接地址现在没有加口令（只在本机能访问），正式做必须加。
3. **测试用 DSH 的“默认工作区”指向你原来那份 DSH 的工作区**（`~/Documents/deepseek-harness/default-workspace`，就是放 news-crawler 的地方）——换了配置目录也没换掉它。我核对过，实测期间那个文件夹没有任何改动。第 1 步要显式设工作区。
4. **你填的 Key 地区选错了**：那把千问 Token Plan 是国内套餐，DSH 里“qwen-token-plan”连的是新加坡，所以报“密钥无效”；换成“qwen-token-plan-cn”就通了，里面有 DeepSeek V4.1 Flash。
5. **Key 出现在聊天记录里了**：这把 Key 你在对话里直接发过，建议测试结束后去百炼后台作废、换一把新的。
6. 确认卡贴在输入框上时比输入框宽（占满整列），样式要按 DSH 规矩调。

## 三、要写进第 1 步方案的 4 件事

1. **【要你拍板】任务卡做成 DSH 会话**（推荐）：每张任务卡在 DSH 里就是一个会话（DeepSeek 的 superagent 原型也是一张工单一个执行会话）。好处：贴输入框的卡、轨迹、后台任务、右栏，这些 DSH 现成的东西在任务页里直接能用，不用自己做；坏处：要设计“会话”和“卡片”怎么对上，左栏要能把任务会话和聊天会话分开。不这么做，就要自己写轨迹页、后台任务显示。
2. **左栏用 DSH 原生的“任务”入口，还是坚持“对话 | 任务”切换标签**：前者现成、符合“界面完全沿用 DSH”；后者和图一致，但要替换 DSH 的会话列表。我倾向前者，你看实物后定。
3. **接口换成 DSH 正式方式**（桌面版必须），并给转接加口令。
4. **超级助手的说明书 + 工作区绑定**，以及 Key 接钥匙串（半天）。

- 插件：`~/Desktop/dsh-实测/superagent-plugin/`（`@local/superagent`，纯 JS 免编译，`dsh plugin --profile web add link:<路径>` 装进隔离 profile）。Host 半侧 `index.js`：`propose_task` 工具（一次只留一张 open 提议）+ `ctx.webServer.register({kind:'prefix', path:'/sa-api'})` 转发到 `desktop/server.py`（18811，X-Chat-Token）和 `bridge.py`（`collab.tasks.new_card` + `desktop.clerk.tasks.launch('plan')`）。浏览器半侧 `client.js`：手写 `window.__ModuleLoader__.load({id, factory})`，注册 `sidebar.panellist`（id=superagent-tasks）+ `main` keyed slot（任务页）+ `conversation.input.dock`（确认卡，session 作用域，组件拿得到 sessionId）。
- 启动：`DSH_HOME=~/Desktop/dsh-实测/home DSH_AGENTS_HOME=~/Desktop/dsh-实测/agents-home pnpm dsh web --no-open --port 3091`。DSH_HOME 不改默认工作区位置。
