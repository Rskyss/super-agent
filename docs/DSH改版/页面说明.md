## 首次使用：设定超级助手（路径与流程，待用户过一遍）

**目的**：第一次打开软件，什么都没配，先让超级助手能开口。这是最重要的第一步，设好后一般不再动。

### 路径
1. 打开软件 → 看有没有设好过超级助手（钥匙串里有超级助手的 Key，且上次测试过能回话）。
   - 设好过 → 直接进首页（01）。
   - 没设好 → 进 **00a**。左栏空（“还没有对话”）、新会话按钮和输入框是灰的。
2. **00a** 选服务商（默认 DeepSeek）→ 粘贴 API Key → 自动验证（1–2 秒）。
3. 验证结果：
   - 通了 → **00b**：下面展开模型列表（实时向服务商要），选一个 → 点“确认”。
   - 无效 / 连不上 / 被限流 → **00d**：只在 Key 框下提示原因，不展开模型，可重新粘贴或换服务商。
4. 点“确认” → 让模型真回一句话：
   - 成功 → **00c**：此时才把 Key 存进钥匙串、把模型记为超级助手用的。页面立刻变成可以直接说话的样子（见下）。
   - 失败（余额不足、模型暂时不可用）→ 停在 00b，写明原因，什么都不保存。
5. **00c**：设好超级助手就完成了，页面就是普通的新会话页，没有“下一步”提示、没有“继续”按钮。**用户 11-14 定：配好大模型就是最主要的事，之后做什么由用户自己决定；这工具现在只给自己用，不要多的提示。**

### 中途情况
- **中途关掉软件**：没点“确认”成功前什么都没存，下次从 00a 重新开始（Key 不留在界面里）。
- **在 00b 换服务商**：Key 和模型列表清空，回到 00a 的状态。
- **想跳过**：不能跳过。超级助手没有大模型就没法开口，所以这一步必填。设置可以点开，但此时里面没有可配的内容。
- **以后想换大模型**：设置 → 积木库 → 大脑 → 超级助手在用的那一项 → 更换，重新走 00a → 00c，新旧对话记录都保留（页面 06a）。“通用”页不放超级助手模型。

### 00a 第一次打开：只有服务商和 Key
- **这页是干什么的**：让用户选服务商、贴 Key。
- **页面上有什么**：标题“配置一个大模型来做你的超级助手吧”、一句说明（超级助手负责和你对话、帮你把超级助手配好，这步设好后一般不用再改）、服务商（DeepSeek、阿里百炼、腾讯云、其他）、API Key 框（默认光标在这里）、“去哪里拿？”、一句“只存在这台电脑的钥匙串里，不会上传”。左栏空，新会话和输入框灰。**用户 11-14 定：去掉顶部“①②③”三步提示和“按量付费”那句话（00a–00d 四页都去掉）。**
- **各种情况**：
  - 正常：贴入 Key 自动验证，进 00b 或 00d。
  - 没数据：框为空不提示。
  - 选“其他（OpenAI 兼容）”（**用户 11-15 定**）：多出一个“接口地址”框（例 https://api.example.com/v1，下面一行小字“服务商文档里写的‘OpenAI 兼容地址’，一般以 /v1 结尾”），兼容 OpenAI 写法的服务都能接。不用填模型名：Key 通了照样自动拉模型列表让你选。草图 00e。<!-- 原：**这条待确认：现有超级助手接的是这种通用接口，所以“其他”可行，但要填的地址、模型名怎么写才不吓到普通人，要再想。** -->
  - 边界：粘贴时的空格、换行自动去掉；Key 不进聊天记录和日志。
- **来源**：整页用 **DSH 现成**的输入框、按钮、提示零件；“验证 Key”的做法**改现有**（现有超级助手用的是兼容 OpenAI 的接口，已有出错提示：401/403 Key 不对、402/429 额度或太频繁、404 地址或模型不对，直接沿用这些说法）；钥匙串存取**改现有**（现有 Mac 窗口已经会把 Key 存进钥匙串）。

### 00c 超级助手设好后：新会话页
- **这页是干什么的**：超级助手设好之后用户看到的页面，就是平时开新会话的样子。
- **页面上有什么**：一行标题“今天想交给我什么事？”（不带图标）；标题下面、页面正中间一个输入框（提示“跟超级助手说你想做什么…”，左下“＋ 附件 / 截图”，右下发送键）。左栏仍是“还没有对话”，“新会话”可点。**没有**成功提示卡、没有示例按钮、没有“接入什么”的引导、没有“继续”。输入框在中间（学 DSH 的新会话页），不放在页面底部。
- **各种情况**：以后每次“新会话”都是这个样子（有了对话后，左栏会有历史）。想接入大模型、命令行工具时直接说，超级助手出确认卡（页面 12）——和平时聊别的事没有区别。

- **验收**：确认模型成功后直接显示这页；输入框可用，在页面正中。
- **和 DSH 新会话页的差别**：DSH 输入框上方有“工作区”“模式”选择，下方有权限、模型、麦克风。我们没有“模式”（超级助手自动判断）、没有模型选择（设置里一次性配好），其余待逐项讨论。

### 00d Key 没通过
- **这页是干什么的**：Key 验证没通过时的样子，不展开模型。
- **页面上有什么**：Key 框右侧红色短标签“✕ 未通过”；框下面**一行短的红字原因**；再下面两个链接“去哪里拿？”“换一家服务商”。
- **各种情况（原因那一行写什么，字要少）**：
  - Key 被拒绝（401/403）→ “Key 不对或已失效，请重新复制”
  - 额度用完或请求太频繁（402/429）→ “额度用完或请求太频繁，稍后再试”
  - 连不上 → “连不上，请检查网络”
  - 右侧标签三种都用“✕ 未通过”（因为不一定是 Key 的问题），具体原因看下面那一行。
- **来源**：**改现有**（现有 desktop/clerk/client.py 已区分这几种失败，说法改短）；标签、链接用 **DSH 现成**零件。
- **验收**：用错 Key、没余额 Key、断网，三种情况下面那行原因各不相同；都没有展开模型。

## 00b Key 验证通了：展开选模型

**这页是干什么的**：第一次打开时，Key 验证通过后，展开模型列表让用户选一个，点确认后超级助手就能说话。上一页 00a（只有服务商和 Key），下一页 00c。

**页面上有什么**：标题和说明同 00a（无三步提示）、服务商选择（DeepSeek 等）、API Key 框（右侧显示“✓ 有效”）、“选一个模型”区（可滚动的单选列表）、“确认”按钮。输入框和左栏都是灰的，接好之前不能用。

### API Key 自动验证
- **正常**：粘贴 Key 后自动验证，框内右侧先转圈，约 1–2 秒后变成“✓ 有效”，下面才展开“选一个模型”。
- **没数据**：框是空的时不验证，也不提示。
- **出错**：
  - Key 被服务商拒绝：显示“✕ 无效”，见 00d，不展开模型。
  - 网络连不上：提示“连不上 DeepSeek，检查网络后重新粘贴”，不说成 Key 无效。
  - 服务商限流（请求太频繁）：提示“服务商让稍等一下，一会儿再试”，不说成 Key 无效。
- **边界**：粘贴时带的空格、换行自动去掉；Key 只显示开头和末 4 位，中间用点遮住；输入框里的内容不进聊天记录和日志。
- **来源**：验证方式**改现有**（现有 collab/blocks_check.py 里用 Key 请求服务商的做法）；输入框、转圈、对勾用 **DSH 现成**的零件。
- **验收**：贴一个有效 Key，3 秒内出现“✓ 有效”并展开模型；贴一个无效 Key 出现 00d；断网时提示的是网络问题。

### 模型列表
- **正常**：Key 通了立刻向这家服务商要当前可用的模型，**全部列出来**，列表区域固定高度，右边有上下滚动条，滚动查看，不折叠、不分页。单选；**默认不选（用户 11-15 定），没选之前“确认”是灰的，旁边小字“先选一个模型”**。
- **去掉的（用户 11-14 定）**：“已获取到 N 个”那句话、“重新获取”链接、“推荐 · 便宜快”标签、“另外 N 个…”折叠行都不要。
- **想看服务商新出的模型**：这一页没有刷新按钮；每次打开这一步（或在设置 → 通用 → 更换 里重走）都会重新向服务商要一次最新的列表。
- **没数据**：拿到 0 个时，不显示“确认”，显示“这个 Key 现在没有可用的对话模型，可能账号还没开通或余额为 0”，并可重新验证 Key。
- **拉取失败**：提示原因（网络不通、服务商出错）和“重试”，不显示“确认”。
- **边界**：只列能对话的模型，不列向量、图片等其他用途的；模型名很长时整行显示不下就截断，鼠标放上去看全名。
- **来源**：获取列表**改现有**（现有 collab/blocks_check.py 请求 /models 的做法）；单选列表、滚动条用 **DSH 现成**零件。
- **验收**：模型多于列表高度时出现滚动条并能滚到最后一个；点“重新验证 Key”后列表会更新；用没余额的账号，出现“没有可用模型”且没有“确认”。

### 确认
- **正常**：选好模型点“确认”，让模型真回一句话（约 1 秒），成功后进入 00c，并把 Key 存进钥匙串、模型设为超级助手用的。
- **出错**：回话失败（余额不足、模型暂时不可用）：停在本页，写明具体原因，不保存、不进下一步。
- **边界**：没选模型时按钮是灰的；连点两次只发一次请求。
- **来源**：**改现有**（现有“检测”会让模型回话）；按钮、状态用 **DSH 现成**零件。
- **验收**：余额为 0 的 Key 点确认，停在本页并说明原因；正常 Key 点确认后 3 秒内进入 00c。

## 12 接零件确认卡

- **这页是干什么的**：用户在聊天里说要接一个东西（例：“帮我接上高德地图，再做一个查两地路线和耗时的能力”），超级助手判断是“接零件”，出确认卡。做法照搬 DSH 创造模式（需求共识第五a节）。
- **页面上有什么**：（11-14 去掉“谁来做”一行：你只和超级助手打交道，后台谁干只在任务卡右栏每步小字里写。）用户的话；超级助手一句说明（几件事先做哪件、它已经查过什么）；确认卡①：标题“接入零件 · 高德地图”、类型标签“搭建 · 接零件”和“不对，改成…”、状态“等你确认”；表格五行：
  - **是什么**：高德官方命令行工具，能做什么；标“官方”（民间的要标出来并提示风险）。
  - **怎么接**：三种之一——已有现成插件，直接装 / 有官方 MCP，配一下就行 / 只有命令行，我照 DSH 的做法写一个接入插件。
  - **要做的事**：这次任务会走的步骤，一行写完。
  - **需要你**：安装前再确认一次（会往电脑里装东西）；Key 你自己填，超级助手看不到明文；最后看试用结果，满意才启用。
  - 按钮“确认，开始接入”“我要改”。
  - 一句话里有两件事时，**一次只出一张卡（用户 11-14 定）**：超级助手说“这是两件事，先帮你接高德；接好了我再跟你说做能力的事”，只出第一件的卡；第一件做完后，在同一个对话里再提第二件、出第二张卡。
- **各种情况**：
  - 超级助手出卡前先做只读的查询（积木库里有没有、有没有现成插件或官方 MCP、这台电脑装没装），查询不改任何东西。
  - 已经接好的：不出卡，直接说“已经接好了，在 设置 → 积木库 里”。
  - 只有民间工具：“是什么”那行标“民间”，并说明可能的风险（如封号），用户确认后才接。
  - 用户点“不对，改成…”：改成别的类型（如“只是聊聊”）后按那一类走。
  - 点“我要改”：在聊天里接着改，改完重新出卡。
- **来源**：确认卡外观用 **DSH 现成**零件；“查有没有现成的”用 **DSH 现成**（插件管理器能列出插件和组合包）加**改现有**（我们积木库已有的检测）；“拆成几张卡”**新做**（DSH 没有确认卡）。
- **验收**：说“接上高德”出这张卡，五行都有；说“接上高德，再做个查路线的能力”只出接高德这一张卡，接好后超级助手主动提做能力的事；已经接好的不出卡。

## 13 接零件任务：等你填 Key

- **这页是干什么的**：点“确认，开始接入”后生成的任务卡（左栏“任务”里），进行到需要用户填 Key 时的样子。
- **页面上有什么**：标题“75 号：接入高德地图”和状态“搭建 · 等你填 Key”；中间是这个任务的对话：已发生的几行（你确认了 / 查了这台电脑 / 你同意安装、已装好）和“请你填高德的 Key”卡（去哪里拿、只存钥匙串、粘贴框、“保存”）；右栏七步进度：
  1. 查这台电脑（装没装）
  2. 安装命令行（**你确认后**程序执行）
  3. 你填 Key
  4. 写接入插件（照 DSH 说明书写，把命令行包成几个工具）
  5. 试用（用你的 Key 真跑一次，如查北京到天津的路线）
  6. 复查（复查员查：会不会乱访问、出错提示清不清楚；不过就改，最多 3 轮）
  7. 你确认启用
- **各种情况**：

## 03 干活确认卡

## 03b 点确认后：聊天里生成任务卡

- **页面上有什么**：
  - 原来的确认卡收起成一行：“需求 · 72 号 · 已确认”，下面一行摘要（要做什么 · 几条验收标准 · 你拍板的答案；没答的问号标“按建议”），点“展开”看全文。任务编号在这一刻才有。

## 04a 任务页：等你批方案

- **这页是干什么的**：建卡后调度员写好方案，在任务卡里拿给你批。你批了才开工。这是 03b 和 04 之间的一步（旧图里没有，11-15 补画）。

  - 右栏：7 步——调度员写方案 ✓（工具 · 模型 · 强度 · 用时）→ **你批方案**（黄圈，“等你 · 几分钟”）→ 写测试 → 写代码 → 跑全部测试 → 复查（最多 3 轮）→ 你验收。

- **各种情况**：
  - 问号不答也能批，按建议走，并在右栏“你批方案”那步写“1 个问题按建议”（和 03 同一条规矩）。

  - 调度员写方案失败：右栏这步变红，超级助手说清原因，给“重写一次 / 不做了”。
