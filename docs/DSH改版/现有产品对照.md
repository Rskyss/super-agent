## 五、今天定的、要落到各处的调整（清单）

1. 叫法：行政 → 超级助手；需Claude介入 → 停下了 · 需要你决定；界面上不出现 Claude。
2. 首次使用只配超级助手；调度员用到时才接（03c），设置里也能接（06 角色块）。
3. 一次只出一张卡；等你点的卡贴在输入框上面（03、03c、04a、05、10、11、12、13、13b、14）。
4. 确认卡：问号没答可直接确认按建议；“不对，改成…”改类型（19）；18 不做。
5. 任务卡：建卡后第一步调度员写方案 → 你批方案；右栏 = 两步固定 + 所选流程的步骤；中途改验收标准先出确认条。
6. 验收：先预览再放进项目；停下时四个按钮；任务页加“对话 | 轨迹”，顶上显示后台任务。
7. 任务总览 09：统计数字 + 按类型标签 + 搜索 + 表；“任务”数字只数等你处理的。
8. 能力卡、积木块由超级助手做；任务卡要调度员。
